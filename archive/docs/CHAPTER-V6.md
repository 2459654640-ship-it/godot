## 故事结构

- 随队：水厂取件 → 回程绕行 → 老兵、公社与中尉的岔路冲突 → D-6 回家 / 嘉奖线 / 公社。
- 独行：初遇谢尔盖 → 选择同行或独自找公社 → 谢契电台 / 公社联络 → 北线星城。
- 公社：安娜的请求 → 正式探访 D-6 煤运区 → 核实身份与照护 → 返回公社。也可以选择留下，或继续追查东方-7。
- 星城：解除内门联锁 → 父亲与谢苗诺夫的往事 → 留在测控、带资料回家、谨慎联络或发送坐标。

现有九个可达终章：水重新流动、一杯热茶、轮班表上的名字、归家之日、自由的分量、另一班守夜人、把面包分给活人、远方有人回答、海那边的回声。终章是本轮改编的落点，没有逐字复刻 HTML 的全部旧分支。与父亲相见时可直言、表达怨恨或暂时沉默；不同回应保存在手记中。

新增剧情与条件保存在 `data/campaign.json`；`campaign.gd` 负责条件和一次性奖励，`campaign_maps.gd` 负责设施几何与家具。物品交接和耗材会核对库存，已经领取的奖励不会重复发放。主线不要求在开场购买某件物资；干电池与绳带是可选办法。

## 界面、素材与声音

图文过场覆盖整个视口，地图 HUD 不透出；正文可滚动，选择区固定在下方。暂停、背包、保存和恢复仍可使用。新设施与任务进入日志，地图页只增加已到访设施的标签。

D-6 下层增加独立楼梯间、下层平台、踏步、扶手、指路牌和灯；不同工区的地面做材质、尺度和色调区别。新增一张 AI 生成的旧波纹铁皮贴图，其余木纹、混凝土、人物、头像和旅程插画优先复用。新人物暂用现有角色美术作为外观，不声称已制作全套新人物立绘。

原有 50Hz 合成通风循环停止使用。增加低音量的原创稀疏旋律、清晰脚步、按钮、物件操作、翻页和保存提示音。总音量、背景旋律、音效分别控制并保存在用户配置中。音频使用离线生成的 PCM，不依赖在线服务；没有人物配音。

中文字体子集补入本轮文字。开发时修改文案后，可在安装 Noto CJK 与 fontTools 的机器上运行 `python3 tools/subset_fonts.py`，完成后串行导入资源。

## 存档与验证

保留 version=1 格式；新增状态都在可选 flags、物品、对话和经济字段内。旧 v5 的水厂外围 / 初遇谢尔盖终点有明确继续按钮。换地图会携带同一份剧情、物资与记录；图文中途存档会恢复到原面板。终章可保存、查看手记、回到原有离站前检查点。

`./tools/run.sh --test` 串行运行原有回归和新增章节、界面流程检查。画面采集使用 `tools/visual_capture_v6.gd`，需可用 X11/OpenGL；不能将 headless 输出称为实机画面。实际结果见 [VALIDATION-V6.md](VALIDATION-V6.md)。

实时战斗、室外 3D 地图和全套新增人物动作不属于当前玩法；本轮完成的是以室内探索和图文选择为核心的主线版本。
