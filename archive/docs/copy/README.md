# 全文案与分支校订本

`地铁1982-v13-全文案与分支校订本.docx` 是独立可编辑的 Word 文件。可用导航窗格按章节、NPC 或任务定位，用修订、批注或直接改字进行校订。修改 Word 不会自动修改工程。

章节包括：最终生效的图文过场与选择；各设施 NPC 的开场变化、选项、前置与奖励；任务阶段与目标；物品、交易物资和十八册刊物全文；D-6 分层对话及全部系统文字；剩余 JSON 与已被覆盖的旧模板。附录包含图内告示示例、状态设置位置，以及重复句子的其它触发位置。

文档保留稳定 ID、文件与行号。条件以中文解释并保留状态名。对于脚本动态生成的文字，保留模板、函数、分支条件及拼接语句，避免把某次游玩的数字误当固定台词。旧基础模板与运行覆盖文本分开标明。

`runtime-v13.json` 是 Godot 实际解析后的 54 个过场和集中常量；`copy-index-v13.json` 是文案字符串、出现位置、条件和源文件校验索引。导出器对非注释中文／西里尔文字符串及可识别界面标签执行逐项覆盖核对，未覆盖时拒绝生成成功结果。图中装饰字不可靠时保留原图供圈改。

需要 Godot 4.6.3、Python 3 和 python-docx，项目资源须已导入：

```sh
godot --headless --path . --script tools/export_copy_data.gd
python3 tools/export_copy_doc.py
```

应从工程根目录执行；第二步核对源文件哈希，快照过期时会要求重新执行第一步。Word 目录可在打开后右键“更新域”；导航窗格可直接使用。
