# Optional user-supplied cue

The game currently plays the original `anna_elegy.wav` at Anna's classroom aftermath. It is not *Here’s to You*.

A properly licensed user-supplied recording or authorized MIDI render may be placed here as `heres_to_you.ogg`; Godot imports it and the same aftermath cue selects it. Keep attribution and authorization with the asset. No commercial recording or melody transcription is included by this update. Ordinary radio tracks remain separate.
