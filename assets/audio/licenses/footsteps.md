# Footstep source

Walking samples are adapted from `sounds/walking.ogg` in [Kenney Starter Kit 3D Platformer](https://github.com/KenneyNL/Starter-Kit-3D-Platformer), commit `3fa8a04b1c01ab23db43123d4ce814a34c3fc7f0`.

The upstream README explicitly licenses included sound effects under [CC0](https://creativecommons.org/publicdomain/zero/1.0/). The repository MIT notice is also retained here. This replaces the previous synthesized pitched impact. Four steps are cropped, filtered and gently faded, with no added sine-wave strike.
