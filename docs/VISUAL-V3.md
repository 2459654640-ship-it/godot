# D-6 v3：绘画人物、完整墙体、对白

在现有项目和 `d6-prototype` 分支上更新，没有重建关卡或改写任务系统。

## 人物与物品

采用 **真实 3D 场景 + 八方向绘制人物**。这是固定等距镜头下的混合表现，不是把旧的简陋模型加一个卡通着色器，也不是宣称已经制作了完整的 3D 骨骼角色。方向图有半写实的脸部、手绘材质与轻微像素颗粒，角色有独立轮廓、年纪、发型和服装。

11 个设计覆盖伊万、谢苗诺夫、妮娜、米哈伊尔、加琳娜、柳德米拉、科瓦廖夫、伊戈尔和 3 位环境居民。五个绘制角度经左右镜像得到八方向。伊万另有左右步幅，形成 idle/left/idle/right 行走循环；NPC 在现有短距离让路时使用轻度网格变形。不是完整的 NPC 日程或全身动作库。

图像切分后统一脚底锚点、尺寸和角色尺度，保持 1.75m 玩家胶囊。绘制面深度测试，接受实际家具遮挡；独立体积投影和接触阴影把人物融入场景。接近时按图像 alpha 边缘显示细轮廓，不在脚下放互动圆圈。相同人物的头像从同一套素材裁出，避免立绘与实机相貌不一致。

14 种任务物品重新绘制，另留背包与杯子两张备用图。图标已实际用于背包与底栏。墙面、地砖、木纹、混凝土、毛毯和地毯也采用本轮生成的材质；颜色、法线和粗糙度用于实体网格，不把参考图当作背景。

原始 AI 图和整理说明：[art-source](../art-source/README.md)。没有声称使用工具未公开的特定模型名称。角色图集及法线/粗糙度整理为离线制作流程，运行游戏不联网、不需要 Python。

## 墙体空缺与闪烁

v2 把前墙固定削到 0.82m，保留上方的门梁、管线。这是上一版设计造成的空缺，不能靠调整深度缓冲修复。v3 所有墙体恢复 **2.70m 高、约 0.25m 厚**，保留门洞、梁柱、原有碰撞和新增获准的相邻卧室隔墙。`walls-complete.png` 展示同一场景关闭渐隐后的完整墙体。

更早 v1 的共面压顶 Z-fighting 与纹理采样问题见 [v2 记录](VISUAL-V2.md)。v3 继续使用先求矩形并集、再挤出外壳的方式，没有重新引入重叠墙皮、共面压顶或 Nearest 无 mipmap 采样。

动态遮挡方案：

- 用与正交相机平行的视线检测玩家全身及周边空间，后墙不被无故隐藏。
- 连续遮挡约 90ms 才进入渐隐；离开检测区域后保持约 450ms，边界增加 0.35m 迟滞。
- 透明度限速渐变，不按帧直接开关显隐。网格、变换、真实墙高和碰撞一直保持。
- 合并外壳避免相交薄片；透明材质写入深度。固定镜头方位下按投影深度确定墙段/附着构件的固定绘制优先级，相机平移不能颠倒顺序。
- 柔和 alpha 混合；没有每帧随机噪声或时间抖动。初测过有序覆盖，因点阵明显已撤掉。
- 门框、部分高处管线与招牌共享对应墙段渐隐。阴影保留独立完整外壳，避免光照随淡出跳变。低墙脚留有连续边界帮助导航。
- Tab 总览时，前方墙段进入渐隐以便阅读整层；离开总览后恢复按人物遮挡检测。

当前镜头可缩放、平移，方向固定。固定绘制优先级对应现有方位；未来加入自由旋转镜头时需要随方位重新分区和排序。

## 文案

阅读了用户提供的 DOCX 和 HTML，将其作为早期剧情/口吻参考，没有把附件里的“最终版”等字样当成开发指令，也没有把后续父亲、东方-7或地表章节定稿。

本轮重写 19 处交互正文和实际动作结果，删掉“本次新增人物”“用于测试的压缩时序”“原型内不赠装备”等场景内开发说明。对已经取空的箱子、已修好的阀门/监测箱、已领装备、已开门等状态分别写正文，避免任务完成后 NPC 继续重复求助。

修正早班提到晚饭、远离收音机时推过收音机、领防毒面具却称口罩、维生素让手抖立即恢复等问题。正式路线仍明晨出发；离站记录用“在气闸候车区等过一夜”的文字衔接，避免早晨对话后立即宣称同日随队出发。

7 名主对话 NPC 各有 3 个日常话题，谈夜班、借围巾、厨房留汤、配给账簿、修电路和彼此评价。闲聊不发奖励、不新增任务状态字段、不抢先揭示后续剧情。台词暖米色，叙述灰绿色，禁用条件弱化显示；手记随信息增加办事记录，不把所有解法一开始就列出来。

任务与存档保持：原有动作 key 和可执行条件、flags/items/route/ending 的变化、一次性奖励与消耗、NPC 锚点、19 处入口和碰撞记录。早期存档可原样加载，文案变更不要求迁移。

## 验证与实机截图

```sh
./tools/run.sh --test
./tools/run.sh --headless --fixed-fps 60 --script res://tests/visual_contract.gd
./tools/run.sh --headless --script res://tests/narrative_contract.gd
```

原有主回归覆盖路线、存档、门口双向穿行、206 个墙角、220 次实体接触面探测和 NPC 让路。视觉契约检查完整墙高、正确绕序、无重叠压顶、原有坐标/碰撞包络、绘制资源、实际旧存档加载、渐隐保持/恢复与短暂视线中断。文案契约对照 `c0441b4` 的实际行为快照，遍历 9 条路径的每个前缀，比较所有原有选项条件和状态/奖励/消耗，并检查 21 个闲聊无任务副作用。

本轮结果：**主回归 1189/0 失败；视觉与兼容 815/0；文案与任务契约 1753/0**。墙体网格 2118 个三角面、533 个压顶单元，绕序错误和重叠压顶均为零。角色移动/让路函数摘要与原版相同，全部原有 NPC 锚点、入口和碰撞包络通过对照。

沿墙实际移动约 4.36m，记录跨度 103 个物理步，保存 96 组位置与 137 段墙的透明度。移除停留段再统计，每段墙至多一次渐隐/恢复方向改变，没有短间隔来回翻转。另有短暂移开视线再返回的迟滞测试，确认不闪回不透明状态。原始 RGB 取样会包含有意的透明度变化与角色/阴影遮挡，不能直接拿颜色差值当闪烁指标；原始数据和 [分析](screenshots/visual-v3/motion-analysis.json) 一并保留。
