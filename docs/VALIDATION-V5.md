Godot 4.6.3；实机画面为 X11 上的 OpenGL Compatibility / Mesa llvmpipe。软件渲染用于画面正确性验证，不用来承诺玩家显卡帧率。

|---|---:|---:|

| 原剧情奖励、代价及未改动门槛 | 1,753 | 0 |

| 总计 | **4,942** | **0** |

生活层实际探测 141 件家具/墙段、311 个可接近侧面、378 个墙角，探测后验证可退回。门闩关闭时东段不可达，打开后可达；原有卧室、厨房、维修区与管线入口继续测试。

下层有 4,211 个连通的保守半米导航格。所有交互目标通过玩家胶囊和实际视线可达；9 道房间门洞逐一双向实际驱动 CharacterBody3D 穿过。正门与煤运门始终实体阻挡。背景工人和守卫巡走时定期检查胶囊没有穿进墙或家具。

跨层检查真实切换场景：作业层保存 → 上楼 → 从生活层读取该存档 → 恢复作业层位置、余额和聊天记录。使用独立测试存档，不覆盖玩家存档。旧 v4 已离站存档衔接新序章，不生成未读剧情结果。

图形启动检查没有跳过开场：新场景自动醒来 → 点击继续 → 选择老爹对白 → 出门恢复控制 → 点击柳德米拉的维生素选项 → 首任务完成 → 通过楼梯选项到作业层。全部使用实际 Godot UI 按钮回调与运行场景。

商店测试制式/土制弹分账、余额不足、不重复出售唯一伏特加、卖后不能再交给守卫、物资数量/药效/库存/交易账存取。对白测试初始照片选项不显示，重开不重复寒暄且保留发言。过场测试两个选择分支、暂停背包不推进面板、选择区域不被滚动裁掉、不同防护插图及一次性暴露代价。

实机截图在 [visual-v5](screenshots/visual-v5)。开场、聊天、商店、日志、双层全景、下行坡道、正门、医务间、装备库、地图与两条旅程均为运行中的真实帧。插图用于过场，3D 楼层依然是独立几何场景。

资源导入曾因字体更新与并行导入重叠失败，该失败未计为通过。最终采用完整字体生成后串行导入，再运行测试和截图；最终源码包另做无缓存解压验证。
