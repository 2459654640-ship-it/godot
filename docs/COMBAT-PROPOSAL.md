# 战斗讨论稿 · 未实施

已确认：以后采用即时射击与解谜交替推进，老兵全程同行，需要对应战斗动作。用户要求先把本轮菜单、叙事、地图和美术完成，战斗方案另行沟通。因此以下均为待讨论建议，没有作为敌人布置或数值写入游戏。

建议先做水厂一个房间的可玩样片，确认移动、瞄准、命中反馈和老兵行为，再铺满水厂。拟讨论的流程是入口安全区 → 泵厅首次遭遇 → 修配与送电之间的第二次遭遇 → 仓库收尾；应保留观察、整备与读纸条的安静时段。具体怪物种类、数量、触发条件及是否可绕行尚未确定。

| 需要讨论 | 建议起点与取舍 |
| --- | --- |
| 操作 | 保留 WASD，鼠标指向瞄准、按键射击与换弹；镜头、攻击范围和准星表现先在单房间样片验证。 |
| 老兵协同 | 自动选择可见目标、保持射线与通路，避免挡住门；是否可下令跟随、守位和撤退需要确认。 |
| 友军失败 | 是否允许老兵倒地、救援、永久死亡，以及死亡是否影响主线和结局，需要先定。 |
| 经济 | 制式弹既是货币也是弹药，强制遭遇必须有可取得的基本补给，不能因之前购物卡住主线。两种弹的伤害、掉落和购买价均未修改。 |
| 生命与食物 | 现行温和机制保持。战斗伤害、脱战恢复、药物使用时机、饱食是否影响回复都待确认，避免同时引入弹药与饥饿压力。 |
| 动作素材 | 伊万与老兵需要与现有形象一致的持枪站立、移动、瞄准、开火、换弹、受击和倒地；中尉是否参战需要补充确定。先验收一套方向与动作样片，再批量制作。 |

样片应检查：敌人不能穿墙、开火不能穿门、友军不误伤或挡路、加载存档后敌人与弹药状态一致、对话和阅读时正确暂停、失败能从合理的检查点恢复。这些是后续验收建议，并非本轮已通过的战斗测试。
