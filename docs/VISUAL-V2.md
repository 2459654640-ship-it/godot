# D-6 视觉重构 v2

在原有 Godot 4.6.3 工程上更新。优先解决墙体 / 场景表现，补充角色、提示、背包、地图和对白层级。主场景、任务流程与存档仍使用同一套实现。

## 闪烁的明确来源

初版 `Kit.wall()` 用相交盒体拼成剖切墙：墙身显示到 0.55m，护墙板覆盖 0–0.60m，压顶覆盖 0.55–0.60m。护墙板和压顶在 **y=0.60m 有重叠的共面顶面**，墙角 / T 字连接处还存在模块相交。移动镜头时，深度测试无法稳定决定共面区域显示哪一面。这是可由原始尺寸直接复核的 Z-fighting 来源。

另一个独立因素：初版细密纹理使用 Nearest 过滤且没有 mipmap，斜俯视移动中容易出现纹理采样跳动。它与几何重叠是两类问题。本次一并处理。

检查原版后，没有发现墙体透明淡出、按人物位置反复切换墙体显隐的脚本。透明排序不是已确认的主因。相机为正交投影；调整裁剪距离只是提供深度精度余量，不能代替消除共面重叠。

## 修复方式

- 先合并矩形墙体平面，再挤出侧面与顶面。墙角及 T 字连接共用体积，每个截面单元只生成一次顶面。
- 可见墙体厚约 0.25m，后墙高 2.70m；镜头前墙使用固定 0.82m 的实体剖切面。墙身材质不透明，不随人物移动淡入淡出。
- 护墙漆直接画在同一张墙面材质内，压顶使用同一网格的独立表面，不再叠放在同深度的护墙板顶面上。
- 相机 near / far 调为 0.4 / 90，仍覆盖整个层面；材质启用线性 mipmap 采样。
- 保留现有门洞中心和净空，门口补混凝土梁柱、金属包边与灯具护网。原有碰撞包络保持不变，避免视觉更新挤占通路。

## 相邻卧室

根据本轮明确回复，允许小幅调整房内通路，新增了谢苗诺夫房间的三段实体隔墙和一个实际门洞。左侧为老爹的床铺，右侧为伊万的收音机与床铺；门洞连接原有起居区域。

老爹 NPC 仍站在原来的交谈点，其余 NPC、调查点、道具入口与出发门坐标全部保持。隔墙是本轮唯一新增的碰撞区域；地毯、台灯、软枕等都是视觉调整。

为了保证兼容，原有墙体的物理包络仍沿用 v1 的 0.20m / 2.8m。可见实体采用 0.25m / 2.7m，墙面相对碰撞的差异只有数厘米，不改变既有门和走廊的可通行净空。没有为装饰划痕、管箍和灯罩新增微小碰撞体。

## 材质与画面

`assets/visual/` 使用本项目原创、可复现的贴图生成：旧漆分层、露底剥落、漏水污迹、水泥颗粒、磨损地砖、锈钢、木纹、织物。每种 3D 材质包含颜色、法线和粗糙度图，默认 512×512；纹理生成器只用于制作资源，运行游戏不需要 Python 或联网。

海报是原创构图与俄文排印，没有将参考图或整幅背景铺入场景。局部暖光、少量投射阴影与冷色基础照明形成层次，近墙依靠真实厚度和剖切面表达体积。

地板与地基不再参与无用的阴影投射，角色使用四个跟随姿态的简化轮廓投影，减少点光源立方体阴影中的细小部件绘制。人物可见模型仍保留服装、五官和材质细节。这些处理没有增加碰撞或改变角色控制。

人物用连续截面塑造衣摆、腰身、肩颈、头脸和靴子，使用织物材质与极细的反向外壳描边。移动、加减速、胶囊与 NPC 让路函数保持字节一致。此版仍是可继续精修的实时角色模型，未声称已经达到参考图的最终人物美术。

## 提示与阅读

地面的交互圆圈和漂浮方块已移除。最近、距离足够且视线可达的对象显示细暖色轮廓和文字提示；已打开的门不再显示关门状态的轮廓。对话时轮廓隐藏。粉笔线索等平面对象保留清楚的文字提示。

对白内容没有改写：同一份文本交给 RichTextLabel 显示，引用的台词用暖米黄色，叙述用灰绿色，选项和条件仍由原有状态判断。

背包增加 14 种原创道具插图，底栏显示前三件随身物品。地图改成等距导览图，含房间编号、真实门口、玩家方向、NPC 和通行状态；地图仍只提供查看功能。

## 已运行的验证

主回归：

```bash
./tools/run.sh --test
```

包括所有任务路线、一次性道具、门口双向穿行、墙角 / 家具碰撞、NPC 让路、UI 与实际存档恢复。v1 初版检查结果保留在 `VALIDATION.md`，本轮结果单独记录，避免混淆版本。

v2 视觉与兼容契约：

```bash
./tools/run.sh --headless --fixed-fps 60 --script res://tests/visual_contract.gd
```

额外验证以下事项：

- `story.gd` 与 v1 提交的 SHA-256 相同，角色 `_physics_process` 源码摘要相同。
- 对照随项目保存的 v1 基线，10 位 NPC 锚点与 19 个交互入口保留，全部原有实体碰撞记录一致；仅新增获准的卧室隔墙。
- 墙体 1,364 个三角面使用正确绕序；318 个压顶单元没有重叠；所有墙体材质不透明。
- 跟随镜头和角色移动期间，墙体网格、变换与显隐保持不变。
- 所有新 3D 主材质包含 mipmap；14 种道具插图可加载；地面圆圈几何已移除。
- 通过真实文件读写加载 v1 格式存档，无需迁移；新增门洞双向通过，隔墙确实阻挡。如果旧位置恰好落在新隔墙内，原有碰撞恢复会把胶囊推出，不会卡在墙里。

实机截图运行（需要可用显示，本次使用临时 Xorg dummy + Mesa llvmpipe）：

```bash
DISPLAY=:99 ./tools/run.sh --audio-driver Dummy --resolution 1600x1000 \
  --fixed-fps 60 --script res://tools/visual_capture.gd
```

截图来自 Godot 视口，沿墙画面使用实际 CharacterBody3D 移动与原来的加减速。脚本只修改本次测试实例的展示状态，不写玩家存档。截图资源位于 `docs/` 并被 `.gdignore` 排除在游戏资源导入之外。

本轮主回归结果为 **1,189 检查 / 0 失败**，含 206 个可接近墙角、220 次墙体 / 家具接触面移动探测；墙体与兼容契约为 **183 检查 / 0 失败**。另外复制一份不含 `.godot` 的工程，在独立运行目录重新导入资源后，主回归与当时的视觉契约检查同样通过；之后补测的旧位置碰撞恢复也通过。相邻卧室增加隔墙后，原先可达的交互点仍全部可达；关门时东段不可达，开门后连通。

在固定步长的连续沿墙行走中，记录了 16 帧的墙面投影取样。两处无角色遮挡的墙面，相邻取样 RGB 最大差值均低于 1/255；第三处取样会被经过的角色遮挡，不用于墙面稳定性的数值结论。原始数据保存在 `screenshots/visual-v2/wall-motion-samples.json`。这些读数与零共面重叠检查、连续画面一起验证本次修复，而不是凭单张静态截图判断。
