# v5：两层 D-6 与出站序章

用户确认：随队路线推进到水厂外围，自行离站推进到初遇谢尔盖；本轮做经济和弹药库存，射击战斗另在危险场景扩展。原 DOCX/HTML 作为人物语气和事件基线，未照搬后面公社、安娜或父亲结局。

## 开场与文案

新游戏先显示醒来、老爹说明征召与缺水、领取维生素的图文片段，再恢复自由移动。第一项任务是免费领取今日维生素 D，之后去作业层向科瓦廖夫报到。原维修、人情、换班、交涉和管线办法保留，正式装备改到下层装备库领取。

清理了玩家未曾听过却自称「某人告诉我」的寒暄，改成自然询问。未拿到照片或其它条件未满足时，界面不展示相应剧情选项。日志只在发现物品、接到请求或听见情报后加入对应记录，不预列暗格、照片和后续人物线。

聊天记录按真实阅读的旁白、人物对白和玩家发言保存；操作行为属于旁白，口语选择用伊万气泡。旁白和对白分开显示，历史不重新打字，新文本快速显示，回复区独立固定。关掉界面或换层不会丢记录，买卖也记入柳德米拉的对话与独立交易账。

## 上下层与地图

生活层现有玩法继续运行，新增关闭的区域通路、远景走廊和可调查的东侧门。原东南延伸线改成开放下行坡道，拆掉外侧完整围墙与旧箱子，换成木板/铁皮围栏和向下的视觉台阶。边缘保持实体阻挡，离站用交互触发。

新作业层约 50×27m，10 个功能分区：主道、轮班工棚、工具修配、医务间、装备库、正门候车、工人歇脚、征召集合、煤运检票、装卸储运。房间使用旧铁皮和木料实心隔断，医疗与装备服务区保留混凝土；煤斗、煤灰堆、托盘、木板、工具盒、旧桶和床铺使用已有模块。守卫与背景工人复用现有多角度人物，未为无台词群众另做角色模型。

钢门真实封闭，配实体碰撞、门框、加强筋、转轮、控制箱和轨道。轨道延伸到门后，候车区内有电瓶轨道车和守卫。煤运门保持关闭，只说明登记和作业，不向伊万揭示安娜哥哥。中尉从生活层移到下层集合区，其余原六位主要生活区人物保留站位。

楼梯更换当前场景，Session 只在换层时携带同一个剧情状态；不会触发自动存档覆盖。各楼层返回位置保存，地图可查看上下两层，当前位置与居民只在当前层显示。绘制人物、移动和碰撞控制器继续复用，钢板墙也使用迟滞渐隐，碰撞始终完整。

自行：维修坡道 → 隧道异响 → 保持距离与火边陌生人交谈 → 坦白来自 D-6 或暂不透露 → 谢尔盖提出相互找路，停在第一次见面。没有直接替玩家答应同行。无完整防护离站时会承受一次较轻的暴露代价：体力 -8、已受辐射 +12，并明确写在旁白和状态中。重复打开过场不重复扣除；图文暂停可使用物资。
