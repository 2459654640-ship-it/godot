# v10 · 对话校对、公社与水厂细化

本轮沿用现有玩法、剧情分支与十四个终章。角色制作实验单独放在 [伊万样片](CHARACTER-PILOT-V10.md)，正式流程仍使用原角色。

## 对话与任务反馈

核对 D-6 常驻人物、后续设施具名任务 NPC 的问题、回答、角色知情范围和任务阶段。含义明确的问答保留，修改有实际指代、逻辑或阶段问题的部分：

| 问题 | 修改 |
| --- | --- |
| 回程选项称「带水回去」 | 明确运回 D-6 的是两箱净水滤芯，任务提示也指向实际厂区铁门 |
| 木箱说明忽然对比面具滤毒罐 | 按要求改为「木箱里是一批生产于1962年的净水滤芯」，随后说明型号和包装检查 |
| 新对白存在，窗口仍显示聊天记录开头 | 等待布局完成后定位到本次新增段落；直接补全文字也会正确定位，保留旧记录供回看 |
| 水厂两名队员始终重复初到厂房的话 | 查图、卸压取件、送电、装稳滤芯分别有对应状态对白，完成后能询问回程分工和绑扎 |
| 卓娅将回水与遮光混为一谈 | 区分回水泵和 A 棚遮光，指出记录卡、芽菜区照明与复查；完成后认可已做的工作 |
| 四条支线用「对方检查抄页」统一收尾 | 说明具体角色核的是什么、记录说明了什么、物品交到哪里 |
| 支线指路和实际操作点不一致 | 敷料：联络账→水井见证；通风：档案→工牌班次；带盒：移交档案→通信室带盒架 |
| 星城访客未登记，守卫就知道其父亲 | 先报姓名并电话核实，再揭示父亲所在；将「还没下班」的情绪段落移到这次确认之后 |
| 非 NPC 调查里的说话者容易混淆 | 水井值班员与班组工人的直接发言补上明确署名 |
| 伊戈尔被问与老爹往来，回答却像被问身体 | 改为两人的探望和药酒往来 |
| 黄灯对白暗示守卫必定自动离岗 | 说明必须先设法让伊戈尔去总表，黄灯只表示开门窗口 |
| 核对电台簿却凭空提到父亲姓名 | 改为簿中没有人员名册，只能记录呼号与来访时段 |

水厂照明与仓门回路明确由小队携带的临时电瓶供电，主泵仍处于停机隔离状态，不假设废弃厂房一直正常运转。

赴水厂旅程补全人物、动作和因果：六人出发、沿途遇险、确认三名同伴死亡并收好遗物、三名幸存者抵达；明确找什么滤芯、如何装运、谁负责回程。老兵的公社身份与离队打算在休息时交代，实际离队发生在回程岔口。

旧存档保留已做任务、财物、奖励与聊天记录，只重新开放少量修正的信息话题。完成水厂的旧存档可直接听到新的回程对白。新增设施造成某个旧站位被占用时，只将该站位挪到附近可通行处，不重置旅程。

## 图文插画

「门后的温度」保留原有大厅、温室、老妇、居民和暖色构图，将前景伊万修正为短发青年男性。新增水厂内部与滤芯运输插画，分别用于入场和回程，不再用同一张厂区外景或牺牲现场承担这些内容。保留地点连续的合理重复，没有为每句台词机械更换插画。

## 公社

公共区域从木地板改为磨旧的双色石质水磨石；服务房间保留瓷砖。增加站台拱肋、柱脚、墙裙和修补细节，用两幅新绘的苏式工人宣传画表现公社的劳动与公共配给主题。

温室的金属种植槽有土壤、浇灌管和带纹理的曲面菜叶；蘑菇区单独使用两层菌袋架，不与青菜种植槽重叠。补充遮光帘、育苗盘、水桶和补光灯，回水泵有可辨识的机体与滤篮，交互点设在泵前。完成遮光后，实际场景的帘子随状态改变。

## 水厂

分区使用磨损混凝土、旧瓷砖和掉漆铁皮，补上泵座、冷却片、法兰与螺栓、压力表、排水格栅、旧药剂桶、桥架、设备标牌和封存滤芯木箱，保留雪地与厂外残墙。新增设施遵守现有通路，实物障碍加入碰撞检查。

东南出口改成外墙开口中的双扇工业铁门，具有门框、铰链、插销/把手和独立门扇碰撞。确认回程时先显示开门动作，再进入图文旅程，移动与重复操作在短暂动画期间锁定。

本轮没有加入敌人、射击伤害或战斗经济。已有战斗方向仍是即时射击、解谜交替与老兵同行，后续需要单房间可玩样片和具体规则确认。
