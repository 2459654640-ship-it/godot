# v10 · 伊万预渲染角色样片

> 历史记录：v11 已移除游戏本体的样片入口。下面的模型未通过外观验收，现位于独立项目 [experiments/ivan-render-lab](../experiments/ivan-render-lab/README.md)；本页所列角色源文件、脚本和图集路径以该独立项目为根目录。Esc 在独立项目中直接退出。

从主菜单选择「伊万角色样片」。左边是现有伊万，右边是模型预渲染版本。两边同时站立或行走，按 WASD 可切换为手动移动；按钮可切换自动行走、站立、暖光、冷光和暗处，或复位。Esc 返回主菜单。

样片不读取、写入或清除游戏存档，不消耗物资，也不替换正式流程中的伊万或任何 NPC。它用于决定是否采用新的角色制作方式，尚不是已验收的全员美术替换。

## 制作方式

- 采用 MakeHuman/MPFB 的 CC0 人体网格、青年男性形变及骨架权重作为解剖基础；衣服、围巾、背包、鞋、头发和细节由本项目脚本构建并绑定到同一骨架。
- 现有伊万图集作为面部和服装颜色、磨损及细节的投影纹理来源，保留棕色外套、浅围巾、背包、棕发的身份。对话头像继续使用原画。
- 固定正交镜头、40 度俯角、身体尺度与脚底基准。所有方向与动作来自同一个模型，没有逐帧重新生成身体或按图形包围盒缩放。
- 输出八个真实方向，不用镜像翻转背包。每方向包含四帧轻微待机、十六帧行走及四帧手臂前伸姿态研究，共 192 帧。游戏对比入口只展示待机与行走；前伸姿态不代表持枪或战斗已完成。
- 行走用双腿交替与足部目标计算，步幅对应移动距离。彩色图保留柔和局部遮蔽，主照明交给 Godot；另从同一模型输出逐帧表面法线和几何深度。
- Blender 的相机法线 Z 轴在打包时转换为 Godot 视空间方向。深度写入法线图的 Alpha 数据通道，Godot 还原每个像素的位置来计算地面、墙体遮挡及受光。材质接收实际灯光和环境光，移除原来固定亮度的做法；此改变仅作用于样片。

单靠平面位置会误遮鞋底，也会使代理阴影盖住人物。样片因此使用模型输出的深度还原受光位置及可见深度，并预留所有步态的固定画幅边界；打包时拒绝任何贴边裁脚的帧。保留胶囊投影与接触影作为低成本的投影近似，不把它们宣称为全身精确投影。当前验证针对固定俯角的 GL Compatibility 渲染器，尚未验证其它渲染器或任意俯角。

## 源文件与重建

- `art-source/v10/ivan/ivan.blend`：打包纹理的原生模型、材质、骨架和动作。
- `art-source/v10/ivan/base/source.json`：CC0 基础资产的来源、固定提交与文件路径；同目录保留许可证。没有复制 MPFB 的可执行插件代码。
- `tools/build_ivan_pilot.py`：Blender 4.3 构建与离线渲染入口。
- `tools/pack_ivan_pilot.py`：固定单元打包、法线坐标转换与预览动画输出。
- `assets/characters/ivan_pilot`：游戏实际使用的色彩图集、法线图集和清单。

```bash
blender -b -t 3 --python-exit-code 1 --python tools/build_ivan_pilot.py
python3 tools/pack_ivan_pilot.py
./tools/run.sh
```

只看离线美术预览可为构建脚本添加 `-- --preview`。生成动作中间帧位于被忽略的 `art-source/v10/ivan/frames/`；原生模型和最终图集均保留。游戏运行不需要 Blender、Python 或联网。

## 当前取舍

这轮验证比例一致、动作生成与受光流程。脸部精修、头发轮廓、衣服皱褶及与原手绘角色的风格匹配，仍需用户根据实际画面验收。没有批量替换 NPC，没有制作武器、开火、换弹、受击或老兵协同动作；这些应在人物方向和战斗方案确定后继续。
