### 物理与路径

- 北侧 4 扇门、南侧 3 扇门均双向实际驱动 CharacterBody3D 穿行。
- 主通道全长，包括高架管线下方。
- 正门 / 侧门在锁闭时阻挡；主通道不能绕过岗哨直接进入东段。
- 正门开锁后双向通过。侧门需开始等候并进入黄灯期；通过后保持安全开启，避免返程夹门。
- 82 个可接近的家具 / 墙体段，215 次暴露面的真实移动碰撞探测。检查不会穿过实体、不会走上桌面、碰撞后能退回。

- 食堂中央与侧边、工坊箱子附近、检修口前方通路。
- 将实体 NPC 放进门洞，验证侧向让路和玩家可通过；不是去掉 NPC 碰撞冒充通过。
- 0.5m 网格上的胶囊扫查与连通搜索，加上互动距离和视线检查：所有 19 个交互点可从出生区域接近；关闭岗门时东段不可达，开启后可达。

## 已诊断并修正

NPC 初版只向远离玩家的方向移动，会被持续顶着走，已改成短时间侧向让路。新增暖气片初版挤占食堂侧边通路，已移回后墙。临时检修侧门与正门之外的主通道入口已封闭，防止绕过通行条件。静态材质合批后改用世界坐标投影，避免瓷砖被拉成巨大色块。离站前的正式路线预检使用待确认路线，取消时不会覆盖其他选择。截图退出前显式释放临时图像与停止音频，消除退出资源警告。

## 尚未验证或未制作

- 尚无真人长时间手感 / 阅读 / 无障碍可用性测试；自动碰撞覆盖不构成所有操作序列永不卡死的数学证明。
- Windows、macOS、手机、手柄、超宽屏和低于 4.6.3 的 Godot 版本未验证；没有声称跨平台导出已经通过。
- 角色为有服装区分的原创低模占位资产，家具与环境仍是程序化原型，不是参考图级别的最终美术。
- 采用固定切墙，无动态墙体淡出 / 多层楼 / 镜头旋转。NPC 只有短距离让路与回位，不是完整作息、导航或潜行 AI。
- 检修管线以文字结果和位置过渡表达，不含爬行姿态或管内关卡。岗门开通以闩锁状态与门板收起表达，未做正式开门动画。
- 不包含战斗、武器操作、耐久、辐射模拟、水厂、地表或后续长篇剧情。无持枪角色素材冒充完整系统。
- 已保存云环境 `start_skill` 草稿，说明当前启动 / 导入 / 回归流程；未发布该草稿，也未推送仓库到 GitHub。
