# 地铁1982 · D-6

Godot 4.6.3 的等距 2.5D 叙事探索游戏。当前为 **v17：首次相识对话、星城科研设施翻新、伊万步态与电台录音修正**。保留原有核心玩法与手绘风格，包含 D-6 两层、水处理厂、莫斯科公社、谢契、煤运设施与星城。

七张地图的公共区域各有一台桌面收音机，七首完整歌曲分为“夜班来信”“旧日留声”“清晨微光”三个频道，频道与歌名均有中俄文。可选歌、换台、暂停、关闭与独立调音量；公共收音机随距离渐弱，剧情及战斗期间暂时停播。

第七供应点可花 **12 发制式子弹**购买随身收音机，在背包点“收听音乐”，无需额外耗材，可跨地图续播。公共收音机和随身收音机共用播放源，避免叠放。

多人群体沿用统一俯视贴图与有效图像区域。谢契住户区有八张床、带碰撞的布幕、可通行的中央走道；长老与议事桌椅分开摆放。部分房间换用等比适配的靛蓝、橄榄绿和重复纹样地毯。

公社与谢契的 12 位主要 NPC 首次交谈会先互报姓名，再聊来意与日常，之后才出现原有任务。中途离开可以继续，已认识的人物与旧存档会保留交谈记录。

星城增加仪器准备间、环境试验舱和科研记录；测控大厅与试验舱采用折角轮廓，按用途区分地胶、水磨石、防滑胶面、实验瓷砖与墙面。控制席面向主屏，机柜、录音设备、校准仪器和真空舱均有相应设施与通行空间。

伊万正背面行走采用独立腿部绘制，停止用整个人物镜像制造交替步；斜向落脚过渡略微延长。普通、面具、持枪与换弹共用修正。电台《渡口》已替换为新上传的正确录音；误标的《朋友的酒》已移除。

## 运行

安装 Godot **4.6.3**，用编辑器打开 `project.godot`，或在仓库目录运行：

```sh
./tools/run.sh
```

入口为 `scenes/main_menu.tscn`。首次启动会导入素材；存档与声音设置写入 Godot 的用户数据目录，不写入工程。云环境的启动脚本使用 `/workspace/.metro1982` 保存本地运行数据。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对镜头移动 |
| 鼠标 / 左键 | 战斗中瞄准 / 射击 |
| 1 | 手动拔枪 / 收枪；先在背包装备武器 |
| R | 换弹 |
| E | 与当前目标交互；老兵倒地时靠近按住两秒救援 |
| 滚轮 | 附近多个目标时切换选中对象，否则缩放 |
| I | 背包、物品与随身收音机 |
| J / M | 手记 / 地图 |
| Tab | 当前设施总览 |
| 空格 / 点击正文 | 补全当前段文字 |
| Esc | 关闭面板 / 暂停菜单 |
| F5 / F9 | 快速保存 / 确认读取快速存档 |

交互提示显示目标名称与切换序号；按 E 只作用于选中的对象。目标离开范围、被墙挡住或收集品被拿走后，会自动重新选择。
