# 地铁1982 · D-6

Godot 4.6.3 的等距 2.5D 叙事探索游戏。当前为 **v14：回归早期人物比例，校正八方向动作**。保留原有手绘角色和地下设施的美术方向，包含 D-6 两层、水处理厂、公社、谢契、煤运设施与星城。

1962 年核战争爆发时，伊万三岁。二十年后，缺水与征召把他推向地表。他可以随 D-6 小队出发，也可以设法逃离，随后经由不同势力调查北方信号和父亲的下落。加入公社或谢契后还能探索、承担工作、取得信任，再前往星城；终章放在调查和交接完成之后。设施间的地表、隧道与列车行程采用全屏图文互动。

## 运行

使用 **Godot 4.6.3 标准版**打开根目录 `project.godot`，等待首次资源导入，再按 F5 从主菜单运行。不需要 C#、插件或在线服务。F6 仅适合开发时检查单个场景。

Linux / 云环境：

```bash
cd /workspace/godot
./tools/run.sh
```

可用 `GODOT_BIN` 指定 Godot，`METRO_RUNTIME_ROOT` 指定独立用户目录。桌面用户可直接使用编辑器。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 相对镜头移动 |
| 鼠标 / 左键 | 战斗中瞄准 / 射击 |
| 1 | 手动拔枪 / 收枪，武器在背包中装备 |
| R | 装填土制弹 |
| E | 调查、交谈、换层；老兵倒地时靠近并按住两秒救援 |
| I | 背包、药物和食物 |
| J / M | 手记（含收集品） / 手记中的地图 |
| Tab / 滚轮 | 当前设施总览 / 缩放 |
| 空格 / 点击正文 | 补全当前段文字 |
| Esc | 返回、暂停、声音、存读档 |
| F5 / F9 | 快速保存 / 确认后读取快速存档 |

手记区分正在跟进、已接待办、已完成与已失败的任务，未接任务由当地线索提示。对话选项用文字标记和颜色区分任务、会影响流程的决定与闲聊。供应点可切换购买和出售，剧情关键物品受到保护。

公社食堂西墙边有旧训练终端。靠近按 E，选择开始后用左右键移动方块、上键或 X 顺时针旋转、Z 逆时针旋转、下键软降、空格落底，P 暂停、R 重开、Esc 离开。最高分随存档保存，游玩不消耗物资。

## 本轮内容

- 重新提取 V3 的伊万与中尉、V8 首次加入的老兵原图。每次绘制固定使用这些早期参考，恢复较小的头部、手掌和自然身材，更新五套基本装束及三套持枪动作图集与对应头像。
- 普通、戴面具、持枪行走及移动装填的八个方向都包含两侧迈步与中立过渡，按“左—站—右—站”循环。完整姿态统一脚底锚点、身高与曝光，不切腿拼接。
- 补画持枪正反面和老兵背面。老兵的不对称挎包保持同一侧；新增完整的八方向三姿态截图及四相位预览，便于逐帧查看。

以下为 v13 已有并继续保留的内容：

- 伊万普通、戴面具与两套持枪服装统一完整身体比例；普通和戴面具中尉补上两侧迈步。重绘老兵持枪步态与移动装填，站立帧继续作为步态过渡，避免换弹或射击时腿部冻结。
- 校正莫罗、厨师、儿童、谢契长老和谢尔盖的全身图集与肖像。自动对齐完整人形，避免不同原图行高造成裁脚、拉胖。无走路图的单姿态人物固定活动，不再滑动让路。所有居民群体采用与单人一致的场景光照取样，明暗变化平滑过渡。
- 水厂地面、墙面、瓷砖、旧漆铁板采用八种统一的新增材质，按干湿和房间用途分区；加强窗侧补光与局部灯光。保留真实墙洞、导航和低台阶机制。
- 新增六个系列、十八册可阅读刊物：十二处探索拾取、六份已有支线的答谢赠书。手记显示收集和阅读进度；未知刊物以剪影、问号和轻度悬停线索呈现。旧存档已完成相应任务时会补录刊物，不重复发放子弹。
- 公社食堂加入有实体机身、显示器和键盘的方块终端，支持旋转、落底、消行、暂停与最高分。
- 修正支持老兵离队的选择，明确伊万与老兵一同前往公社。提供可编辑 Word 全文案校订本与可复现导出脚本。

以下为 v12 已有并继续保留的内容：

- 公社议事厅缩小、增加三间生产房和锅炉工莫罗；温室扩大并增加不同作物；家庭双人隔间和守备部门加入新布局。新增两条有多阶段调查、选择与过场的支线，委托随进度开放。
- 水厂墙面材质依附真实墙体，修复档案室遮门墙片、地面假门槛和室内积雪。补充六种材质和设备装饰，默认战斗提高到 3 / 3 / 4 只，保留预警与无损重试。
- 修复低讲台边缘的脚部穿模：角色能实际跨上 24 厘米内的低台阶，离开台面恢复地面高度，较高设施与低顶空间仍阻挡。
- 新增独立武器栏和手动拔枪。补主角与老兵持枪迈步，重绘伊万中立过渡帧，删除被放弃的 3D 伊万项目。

以下功能沿用并继续支持：

- 撤回 v11 的切腿、横摆和服装变形，使用完整绘制姿态。人物继续随灯光和遮挡调整明暗；静态角色不假装行走，尚未给每位居民制作完整动作集。
- 公社移除挡门的长墙裙与零散地面补丁，柱子改为贴墙半柱，撤去悬空长梁。公共厅到议事厅采用居中的双扇门，有开合动画和实体碰撞。不同用途房间使用分区地墙材质，食堂长椅面向餐桌，遮光棚回到菌架上方，医务屏风有碰撞。
- 公社补充六组固定居民，共十七人；保留门口与通路净空，不增加随机踱步。对白、任务及过场逐项审校，修改答非所问、隐晦比喻、过时设施指引和玩法矛盾；长对白使用更宽的文字气泡，不刻意省略必要信息。
- 公社增加人民议事厅、厨房、食堂和家庭生活区。谢契改为生活车厢、公共站厅与外侧独立铁轨，补充住宿、餐饮、医护和图书设施。房间用途通过地图查看，移除悬空的黑色用途牌。
- 公社供暖、餐食，谢契炉灶、被褥等支线提供补给。加入阵营会进入后续任务；可经审核返回 D-6 下层，进入独立煤运地图帮助安娜的哥哥。维生素 D 保留为营养配给，不再用于送人换关系。
- 水厂三段即时遭遇与设备解谜交替，老兵跟随射击、可倒地救援。死亡和主动重试恢复本场战斗前的状态，不额外扣资源。主线有基本弹药补给，制式弹继续作为交易货币。
- 收听电台才接取信号调查，后续也可发现频率；星城现场核实才完成。母亲照片可用于父子相认，离散原因和设施交接有后续对话。
- 三个手动槽、三个轮换自动槽和独立快速存档，包含时间、位置、备份与校验。读档需要确认，旧版布局和提前结束的阵营存档可迁移。
- 墙体根据覆盖角色身体的程度渐隐，最低保留约 42% 不透明度。高处管线、横梁和灯具也参与，最低约 38%；碰撞不受影响。

饱食保持温和：只在实际行走时下降，阅读与暂停不消耗，饥饿为零不会持续扣血。水厂污泥区域会积累辐射，抗辐射药可以消减；主线路径可以避开污泥。

## 人物美术

按新的美术方向，v12 已删除未通过验收的 3D 伊万独立项目与预览文件。游戏继续使用 2D 手绘人物。
