# 地铁1982 · D-6

Godot 4.6.3 的等距 2.5D 叙事探索游戏。当前为 **v19：伊万完整人物帧重绘、互动旅程与地表泵站副本**。保留原有玩法和手绘风格，共八张可进入的地图；星城目前只开放外围。

伊万以 v3 原始形象重新建立八方向站姿，分别生成左右迈步，逐方向校验前后腿，再生成普通、面具、持枪、面具持枪和移动换弹的完整人物。每帧都来自完整 AI 人物画稿，按统一身高与落脚基线打包，采用“迈步—站立—另一迈步—站立”的顺序；本版不再拼接头部、上身或腿部，不通过镜像制造另一侧迈步。实际运行的逐方向对照和动态图在独立资料库。

人民议事厅三位居民重新绘制为各自坐在椅子上的完整人物，沿西墙排列、面向厅内，具有独立碰撞和待机节奏。其他背景人群保留原地，增强呼吸、转头和小幅手部调整。主要居民仍在自己的工作范围内活动。

独自离站后，谢尔盖会先介绍公社、谢契与路上的危险，伊万可以追问后再选择去向；没有听过东方-7 时不会出现有关广播的追问。征召路线补充接敌、掩护和伤亡后的点名、遗物交接，新插图展示通往水厂的电车站伏击。

在公社守备或谢契军需处询问地表工作，明确接受委托后可前往 **旧泵站**。首次派工借用左轮，检修梯旁可领取一次性的 24 发土制弹和两卷绷带。清理运货路的三只变异兽、查排水记录、操作西侧泄水阀，再处理北池四只敌人并封存样本。西南检修梯随时可撤回；再次出发会重置兽群，首次补给和委托报酬不会重复领取。额外骨片与组织样本可在聚落收购处出售，商人也售卖可使用的土制弹药包。死亡恢复本场战斗前的检查点和资源，不额外扣除物资。

泵站包括裂纹道路、正确落在铁轨上的废电车、砖砌残屋、沉淀池、管桥、泵机、装卸棚、碎砖、积雪与远处残墙。新增雪地、砖墙、路面和小物图标，并以世界坐标混合雪地纹理，减轻重复铺贴。

星城对外联系稀少，外人没有工作人员名册或可靠的入内办法。介绍信只供外围询问，当前不能进入内部；旧版内区存档迁移到外围，原有物品、刊物与历史记录保留，内区剧情、任务与三本刊物暂停开放。正式进入方式和后续剧情留待讨论。

各图公共区有桌面收音机，七首歌曲分为三个中俄双语频道，普通 NPC 对话不会暂停音乐。伊万卧室旁的剧情收音机也可选择听音乐，不会因此接取广播任务。第七供应点可用 12 发制式子弹购买随身收音机，在背包收听；公共接收机按距离衰减，随身接收机可跨地图续播。误标的《朋友的酒》已移除，《渡口》使用后来上传的正确录音。

公社、谢契首次交谈仍先自我介绍，再出现相关任务；任务、地图、百科和刊物收藏统一在手记内。谢契床铺、布幕碰撞及地毯等此前优化继续保留。

## 运行

安装 Godot **4.6.3**，用编辑器打开 `project.godot`，或在仓库目录运行：

```sh
./tools/run.sh
```

入口为 `scenes/main_menu.tscn`。首次启动会导入素材；存档与声音设置写入 Godot 的用户数据目录，不写入工程。云环境的启动脚本使用 `/workspace/.metro1982` 保存本地运行数据。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对镜头移动 |
| 鼠标 / 左键 | 战斗中瞄准 / 射击 |
| 1 | 手动拔枪 / 收枪；先在背包装备武器 |
| R | 换弹 |
| E | 与当前目标交互；老兵倒地时靠近按住两秒救援 |
| 滚轮 | 附近多个目标时切换选中对象，否则缩放 |
| I | 背包、物品与随身收音机 |
| J / M | 手记 / 地图 |
| Tab | 当前设施总览 |
| 空格 / 点击正文 | 补全当前段文字 |
| Esc | 关闭面板 / 暂停菜单 |
| F5 / F9 | 快速保存 / 确认读取快速存档 |

交互提示显示目标名称与切换序号；按 E 只作用于选中的对象。目标离开范围、被墙挡住或收集品被拿走后，会自动重新选择。
