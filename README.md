# 地铁1982 · v41 东郊冬季街景

完整解压这个文件夹，运行 `Metro1982.exe`。无需安装 Godot；请保留同目录下的 `Metro1982.pck` 和整个 `content` 文件夹。Linux 运行 `Metro1982.x86_64`。

WASD 移动，E 互动，滚轮切换邻近目标。I 背包，J 手记，M 地图，Esc 暂停。1 拔枪／收枪，鼠标瞄准，左键射击，R 换弹，Ctrl 轻步。空格补全当前文字后继续，选择项用鼠标点击。

六个手动档位、三个自动档位及独立“最终行动前”存档。F5、F9 打开档位选择。已有存档保存在原用户目录，更新游戏不删除；旧存档已完成章节可接续新后半部，新旅程能完整体验各阵营重制流程。

十四张地图；公社、谢契、D-6 三条路线；星城需实际技术核验才准入；四类终局需执行现场行动，选方向不会直接结束。终局后仍能探索未完支线。

如果旧显卡的 Vulkan 驱动无法启动，可以从终端运行 `Metro1982.exe --rendering-method gl_compatibility`；画面设置可调整四档画质、分辨率和窗口模式。首次进入场景可能需要建立着色器缓存。

`content/manifest.json` 和 `SHA256SUMS.txt` 提供资源大小及校验值。

本包已做 Linux 原生启动、工程分支和界面检查；Windows 模板已打包，尚未在 Windows 真机进行长时间兼容性与性能验收。音乐包含项目方确认获商用授权的上传录音，以及附 MIDI 的原创合成配乐；第三方许可见 licenses 和 GODOT-LICENSE.txt。

v38 在东郊布置 7 处可绕行的兽群遭遇和 7 名灰狗游荡者。地表出勤沿线共有 87 个搜索容器。按 E 开始搜索，移动可中止。搜到的物品与背包格位同屏，尺寸和估价在右栏，选中背包里的物品可旋转或放回。地表地图的绿箭头标记撤离口。进入聚落后结算本次携带物资，寄存柜可查看回收清单。

v39 通过人物对话和地表记录逐步了解其它聚落。首次访问需核对具名担保；登记后可以沿已获准的联络口往返。按 M 打开新版地图，查看当前任务、联络口状态和撤离方向。

v40 在东郊新增六份可收集资料。它们与旧公寓的家信组成「东郊留下的纸」系列，可在手记中阅读。谢契撤离和 D-6 供水章节的回程场景会反映你在当地做过的选择。

v41 更新东郊的冬季照明、路面和屋顶。公社支线口、旧电车站和工人街诊所使用更细的建筑与车辆模型。地表可搜索容器采用固定双栏界面，通过金色框预览收取后的背包格位。搜刮之前仍需要在容器旁完成搜索。
