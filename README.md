# 地铁1982 · D-6

Godot 4.6.3 的等距 2.5D 叙事探索游戏。当前为 **v26：兽群与交火反馈**。保留现有探索、对话、解谜、即时射击和手绘风格，共九张可进入地图。星城仍只开放外围，内区素材保留。

## 这次更新

水厂、旧地表泵站与阵营线路的兽群加入两种新怪物。伏扑兽先伏低身体，显示扑击方向，随后沿锁定方向扑出；囊喉兽保持距离，鼓起喉囊后喷吐可躲避、会被掩体挡住的实体弹道。蓄势可以被射击打断，扑空后有恢复间隔。每种新怪物绘制站立、两种迈步、蓄势、攻击、受击与倒地七种姿态，使用五个视角加镜像覆盖八方向，整只身体统一比例缩放。老兵继续自动跟随与射击。

近战蓄势标记、扑击方向预警、实际命中／击杀提示与短促音效帮助判断战况。打中墙只显示场景撞击，不冒充怪物命中；反馈音效有独立播放池。新战斗状态保存怪物种类、扑击方向、命中状态与飞行弹道，暂停不推进；死亡仍可无损重试。已打完的旧遭遇不重新生成。

[新怪物动作与战斗预览](https://github.com/2459654640-ship-it/godot/tree/metro-reference-library/updates/v26)。新怪物实际出现在水厂三处遭遇、泵站两处遭遇，以及阵营线路的兽群遭遇；末段持枪敌人保持原配置。

## 保留的 v25 内容

辐射改为五档可逆状态：0–19 正常、20–39 自然恢复减半、40–59 恢复更慢且需要饱食 55、60–79 暂停自然恢复、80–100 绷带与急救包恢复量降至 75%。状态页列明实际影响，跨档有提示，读档按保存值恢复。不会因辐射持续掉血或降低移动速度。抗辐射药降低 20 点；D-6 医务间、矿区医护、公社负责人／医护和谢契军需处可安排免费的污染处置，每次降低 30 点，不影响普通医务治疗的恢复量。

新增 D-6 归队后的首段可玩主线：正式交回滤芯，回家与老爹交谈，听医护讲解取样要求，领取补给，再到旧地表泵站解谜、战斗和封存样本，最后返回本站汇报。中途可以撤回再出发；报告侧重点会开放不同的补给后续。原来的“官方派去敌对公社做技术联络”任务已替换。D-6 的长期阵营主线、完整敌对身份审查和矿区潜行系统仍待后续制作。

矿区首次探视接入有选择的床边过场，探视后可自愿协助工人与医护错开共用支路的清洗、供暖时间。新绘制回家喝茶、矿区床边两张插画；新增 15 个过场节点，重写两处归队节点。加入两首原创 MIDI 配乐《门还为你留着》《地下的晚班》，附原谱和压缩音频，过场音乐淡入淡出。

主菜单、局内暂停和图文暂停共用画面／声音设置：窗口、最大化、无边框全屏，窗口分辨率，保持比例／拉伸填充，三档实际渲染画质，垂直同步及帧率限制。应用后有 15 秒确认，超时自动恢复；确认后独立保存。画质调整三维渲染比例、抗锯齿和动态阴影，不降低界面文字的分辨率。

背包改为分类格子和独立详情栏，显示堆叠数量、装备状态，支持使用补给、装备武器与打开随身收音机；格子只是布局，不增加负重或容量限制。手记增加任务详情，将当前目标、目的地、任务背景分开显示，目标随实际进度更新。

普通居民调整程序步态：沿行进方向迈步，降低脚部抬升并调整步频，取消容易产生外撇观感的横向膝部摆动。工人与妇女接入验收后的正背面绘制迈步，侧面与斜方向保留原站姿和程序辅助；儿童保留原素材。伊万四套认可图集全部保持不变。

地图与位置栏统一显示“D-6生活层”“D-6作业层”。正式随队出站、交回滤芯的人恢复生活层通行，受限来访者仍不能自由上楼。矿区增加七名固定工作、候班人员；安娜哥哥在核实身份并安排探视之后才显示，撤离后人物与互动点一同移除。

## 保留的 v24 内容

安娜可以陪同走到食堂，在调查哥哥之前谈课堂、家人和自己的打算；救援期间她会离开公社，结果发生后再恢复相应的人物和日常。莫罗会亲自走访机修间、锅炉房和守备班，场地协商与试演都有选择，约定与歌词会进入正式演出。支持老兵离队后，在联络线可协助守住交叉口：三名居民实际撤离，三轮来袭与接应进度衔接，战斗检查点仍可无损重试。

长支线分阶段开放，未完成的长委托会暂缓其它长委托的首次接取；主线与已经接受的旧任务可以继续。同行者会等候，移动人物的位置、地图目标及跨地图停靠点随存档保留。安娜与莫罗增加完整绘制的迈步姿态，原站姿和伊万全部贴图保留。新增四幅剧情插画；游戏内检查发现的过场姓名显示也已修正。

存档改为六个固定手动档位和三个独立自动存档，F5 / F9 打开档位选择。档位显示地点、游玩时间、当前任务与保存时间，覆盖前确认。角色位置、物品、任务、对话解锁和记录均保存；交火中还保存敌人、弹药、装填与老兵状态，可恢复当前战斗，也能保留战前重试。旧版存档在单独入口读取。

星城外围与地表旧泵站保持两张独立地图。两处的城市废墟和水处理厂外围背景统一补为四面建筑：真实窗洞、窗框、楼板、局部坍塌屋顶、雪层、烟囱与落水管，使用砖、旧灰泥、混凝土和铁皮贴图。星城入口补上厚门框、门体加强筋和带屋顶的等候棚，室外光照与地表一致。

怪物使用符合自身碰撞体的路线，把迈不过去的矮池沿、路缘和掩体纳入绕行；路点裁剪先检查实际体积能否通过，拥挤时避让、受阻时重新规划。隔着墙的近距离目标不会让怪物原地反复尝试撕咬。持枪敌人也使用绕障路线，开门后更新路线，不穿墙追人。

泵站委托随出站自动追踪，兼容仍追踪广播的旧存档；排水、采样、撤回与交付分别指向当下真正能执行的地点。远处的无线电线索不会冒充地表现场任务。手记其它任务标为“其它进行中的任务”，避免误读为没有开始。

新增三张专用返程插图：泵站检修井、公社值守台、谢契车厢入口。采样成功和提前撤退有不同旁白；不再用 D-6 小队乘轨道车的画面表现徒步返程，也不会在未取样时声称带回了样本。旧存档可直接续玩。

## 已有剧情与系统

加入公社或谢契后，各有三轮出站主线，共六项不同任务。新地图“旧联络线换乘站”包括南控制间、西侧转移点、候车区、轨道与维修设备间。每轮有独立派工、途中对话与选择、两场战斗、调查、接送信号和返程回应。后两条路线的第三轮会遇到持枪封锁队；同一段线路因任务与战争进展被再次使用。每班补给与报酬只领取一次，战斗死亡重试恢复本场检查点资源。

D-6 下层新增病房广播过场，把胜利宣传、伤员和配给手续放在同一个场景中。第一次到作业层会呈现，之后可在医务间查阅。

安娜留在公社教孩子认字，哥哥阿列克谢在 D-6 煤运区。先认识她的课堂，再自愿接下寻亲；核实探视结果并完成一次真实出站任务后，她才收到新的矿区来信。后续包括照护、接送、备用出口、与家属同行、撤离及事后生活。生还和悲剧均有完整后续，结果不会终止阵营主线。准备阶段无倒计时，可在矿区补齐全部条件；风险方案需二次明确确认。生还后，北线主线推进到后期，还能带她去熟悉的地表出口看看。详细条件在独立资料库的剧透说明中。

莫罗排练和巴拉诺娃的家庭记述补充了日常后续过场。新增 8 张剧情插图、62 个过场节点（含分支与抵达节点），其中包含可选择的阵营途中事件。根据已经做过的选择显示相应返程内容，不提前透露未经历的分支。

前往星城外围需要完成本阵营三轮出站任务，再亲自核对东方-7 广播并取得询问信。修好电台或做完一项杂活不再立即解锁。正式加入两方互斥；跨阵营访问需要具名担保并承担一班联络工作，每次访问消耗该次通行安排。正式叛离与星城入内流程仍待后续剧情。

已认可的三套装备完整人物 AI 稿接入运行图集：面具、持枪、面具持枪，各八方向三姿态。普通伊万运行图和基础 24 张原文件保持不变。移动换弹保留完整三姿态步态、换弹计时和音效；专用手部换弹重绘未定稿，未继续使用旧的拼接上身。

四首原创 MIDI 剧情配乐随包提供原 MIDI 与渲染音频，用在来信、课堂、返程、战斗和后续生活等节点。安娜悲剧后播放原创《留给下一班的课》，它不是《Here’s to You》；后者预留用户授权音源替换位置，见 `assets/audio/licensed/README.md`。

《我要你》已替换为用户新上传的俄语录音，原频道和顺序保留。“远洋值守 / Ocean Watch / Океанская вахта”英语频道已配置《月亮代表我的心》《我只在乎你》的中俄英名称和 MP3 路径；两份 WAV 超过附件读取上限，本包尚未包含这两段音频。两首 MP3 补齐并导入后，频道自动启用。海上广播不会自动揭露星城与外部势力的关系。

旧存档保留背包、刊物、报酬与已读历史。旧版安娜探视完成记录作为前段经历接续，不自动判定生还或死亡。新剧情建议新建独立存档，便于体验 D-6 和初识过场；原存档无需删除。

## 运行

安装 Godot **4.6.3**，用编辑器打开 `project.godot`，或在仓库目录运行：

```sh
./tools/run.sh
```

入口为 `scenes/main_menu.tscn`。首次启动会导入素材；存档与声音设置写入 Godot 的用户数据目录，不写入工程。云环境的启动脚本使用 `/workspace/.metro1982` 保存本地运行数据。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对镜头移动 |
| 鼠标 / 左键 | 战斗中瞄准 / 射击 |
| 1 | 手动拔枪 / 收枪；先在背包装备武器 |
| R | 换弹 |
| E | 与当前目标交互；老兵倒地时靠近按住两秒救援 |
| 滚轮 | 附近多个目标时切换选中对象，否则缩放 |
| I | 背包、物品与随身收音机 |
| J / M | 手记 / 地图 |
| Tab | 当前设施总览 |
| 空格 / 点击正文 | 补全当前段文字 |
| Esc | 关闭面板 / 暂停菜单 |
| F5 / F9 | 选择存档位保存 / 选择存档回档 |

交互提示显示目标名称与切换序号；按 E 只作用于选中的对象。目标离开范围、被墙挡住或收集品被拿走后，会自动重新选择。
