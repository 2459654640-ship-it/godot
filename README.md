# 地铁1982 · D-6

Godot 4.6.3 的等距 2.5D 叙事探索游戏。当前为 **v31：固定界面重制与地表再出发流程**，共十一张可进入地图。星城仍只开放外围。

## v31：固定分区与操作流程

背包、商店、任务、地图、收藏、百科、经历记录、对话、寄存、存档与设置接入新的固定界面。主导航、物品格子、目录和详情分区展示；内容较多时切换页码，核心页面不再依靠长页面滚动。背包保留真实占格与拖动整理，分类高亮对应物品；购买、使用和存取后保留选择与所在页。地图保留独立缩放、拖动和标记，切换页面后记住地图视图。

任务列表和当前目标并排显示，区分主线、支线、已结束任务及尚未接取的线索；查看某个已完成任务会打开正确的结果。书刊按系列筛选，正文分页且不删减；交谈按段阅读，回应选项独立分页，旧交谈记录单独查看。六个手动存档同时展示；画面与声音设置使用固定页面。

修正俯视镜头下鼠标指向灰狗上半身时的瞄准偏移：实际射击按屏幕人物位置和身体高度计算，实体掩体仍阻挡子弹。灰狗保留 80 点生命，左轮三次无遮挡命中可击倒，未通过提高伤害掩盖命中问题。

地表死亡返站后新增损失与下一步说明。手记指向真实的聚落寄存柜，可取回备用物资；缺少装备时可借用基础套装，装备齐全后目标切到出站口，继续已有任务。此次是整体重制的第一轮实装；场景、主线后半部与完整质量样章仍需继续制作。实景、测试和[制作标准](https://github.com/2459654640-ship-it/godot/tree/metro-reference-library/updates/v31)在独立资料分支。

## v30：探索、任务目标与室内体验

民房通信站任务支持先发现电台再修电的探索顺序；当前目标会随天线隔离、取件、变配电所维修与播放录音逐步变化。修正序章提前认定伊万已加入小队、安娜对白提前透露哥哥等进度问题，重写一批城区出发与返程旁白。

进入诊所、通信站和新增的工人街住宅时，实际渲染的屋顶、雪层和顶梁隐藏，屋外渐暗，镜头适当收近；离开后恢复。住宅增加分隔房间、厨房、床铺、储物柜与书桌，可找到《厨房桌上的信》。城区共有十四处固定搜刮容器；新增按背包容量收取全部物资，放不下的物品留在原处，搜空状态直接显示在互动名称上。

城区大地图改用北向平面图，显示道路与建筑底图，支持滚轮缩放、中键拖动、目的地标记、重置视图和设施悬停名称。已接受任务的地点可以指示未踏查区域，隐藏遭遇仍需自行发现。手记不同页、背包及其它页面分别记住滚动位置，返回或操作后不再总跳回顶部。

新碎石贴图、材质与住宅细节已接入。截图、验证记录和[后半部章节制作稿](https://github.com/2459654640-ship-it/godot/tree/metro-reference-library/updates/v30)存放在独立资料分支。用户已确认后半部采用“预警与撤离”方向；三条阵营线、父子重逢和四套终局的新增设计尚未实装，本版本不是完整的商业发行版。

地表行动死亡会丢失本次随身的普通装备、弹药与物资；任务物品、进度及已寄存物品保留。剧情战斗仍按原规则重试。此次是一个可玩的城市片区和搜刮循环首版，更多城市分区、完整后半部剧情与商业发行质量仍需继续制作。Godot 4.6.3 可直接打开工程。

## 已有剧情与系统

加入公社或谢契后，各有三轮出站主线，共六项不同任务。新地图“旧联络线换乘站”包括南控制间、西侧转移点、候车区、轨道与维修设备间。每轮有独立派工、途中对话与选择、两场战斗、调查、接送信号和返程回应。后两条路线的第三轮会遇到持枪封锁队；同一段线路因任务与战争进展被再次使用。每班补给与报酬只领取一次，战斗死亡重试恢复本场检查点资源。

D-6 下层新增病房广播过场，把胜利宣传、伤员和配给手续放在同一个场景中。第一次到作业层会呈现，之后可在医务间查阅。

安娜留在公社教孩子认字，哥哥阿列克谢在 D-6 煤运区。先认识她的课堂，再自愿接下寻亲；核实探视结果并完成一次真实出站任务后，她才收到新的矿区来信。后续包括照护、接送、备用出口、与家属同行、撤离及事后生活。生还和悲剧均有完整后续，结果不会终止阵营主线。准备阶段无倒计时，可在矿区补齐全部条件；风险方案需二次明确确认。生还后，北线主线推进到后期，还能带她去熟悉的地表出口看看。详细条件在独立资料库的剧透说明中。

莫罗排练和巴拉诺娃的家庭记述补充了日常后续过场。新增 8 张剧情插图、62 个过场节点（含分支与抵达节点），其中包含可选择的阵营途中事件。根据已经做过的选择显示相应返程内容，不提前透露未经历的分支。

前往星城外围需要完成本阵营三轮出站任务，再亲自核对东方-7 广播并取得询问信。修好电台或做完一项杂活不再立即解锁。正式加入两方互斥；跨阵营访问需要具名担保并承担一班联络工作，每次访问消耗该次通行安排。正式叛离与星城入内流程仍待后续剧情。

已认可的三套装备完整人物 AI 稿接入运行图集：面具、持枪、面具持枪，各八方向三姿态。普通伊万运行图和基础 24 张原文件保持不变。移动换弹保留完整三姿态步态、换弹计时和音效；专用手部换弹重绘未定稿，未继续使用旧的拼接上身。

四首原创 MIDI 剧情配乐随包提供原 MIDI 与渲染音频，用在来信、课堂、返程、战斗和后续生活等节点。安娜悲剧后播放原创《留给下一班的课》，它不是《Here’s to You》；后者预留用户授权音源替换位置，见 `assets/audio/licensed/README.md`。

《我要你》已替换为用户新上传的俄语录音，原频道和顺序保留。“远洋值守 / Ocean Watch / Океанская вахта”英语频道已配置《月亮代表我的心》《我只在乎你》的中俄英名称和 MP3 路径；两份 WAV 超过附件读取上限，本包尚未包含这两段音频。两首 MP3 补齐并导入后，频道自动启用。海上广播不会自动揭露星城与外部势力的关系。

旧存档保留背包、刊物、报酬与已读历史。旧版安娜探视完成记录作为前段经历接续，不自动判定生还或死亡。新剧情建议新建独立存档，便于体验 D-6 和初识过场；原存档无需删除。

## 运行

安装 Godot **4.6.3**，用编辑器打开 `project.godot`，或在仓库目录运行：

```sh
./tools/run.sh
```

入口为 `scenes/main_menu.tscn`。首次启动会导入素材；存档与声音设置写入 Godot 的用户数据目录，不写入工程。云环境的启动脚本使用 `/workspace/.metro1982` 保存本地运行数据。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对镜头移动 |
| Ctrl（按住） | 轻步潜行，降低移动速度与脚步声 |
| 鼠标 / 左键 | 战斗中瞄准 / 射击 |
| 1 | 手动拔枪 / 收枪；先在背包装备武器 |
| R | 换弹 |
| E | 与当前目标交互；老兵倒地时靠近按住两秒救援 |
| 滚轮 | 附近多个目标时切换选中对象，否则缩放 |
| I | 背包、物品与随身收音机 |
| J / M | 手记 / 地图 |
| Tab | 当前设施总览 |
| 空格 / 点击正文 | 补全当前段文字 |
| Esc | 关闭面板 / 暂停菜单 |
| F5 / F9 | 选择存档位保存 / 选择存档回档 |

交互提示显示目标名称与切换序号；按 E 只作用于选中的对象。目标离开范围、被墙挡住或收集品被拿走后，会自动重新选择。
