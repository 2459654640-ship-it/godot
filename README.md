# 地铁1982

Godot 4.6.3 等距 2.5D 叙事探索游戏。**v33 完整流程版**：十四张地图，地表半开放街区与独立设施；从 D-6 序章、三条阵营路线，一直推进到星城“预警与撤离”的四类终局。

[直接下载游戏包](https://github.com/2459654640-ship-it/godot/archive/refs/heads/metro-playable-windows.zip) · [本版实景、流程与校订资料](https://github.com/2459654640-ship-it/godot/tree/metro-reference-library/updates/v33) · [当前美术与地图](docs/README.md)

下载包完整解压后运行 `Metro1982.exe`，无需安装 Godot。包内 `content` 文件夹必须与程序放在一起。Linux 可运行 `Metro1982.x86_64`。两个平台使用相同资源包；存档保存在用户目录，更新游戏文件不删除存档。

## 这次的故事与玩法

公社的药品和医护护送之后，继续找回失联运输员与私人书信，再处理供暖通知和住户实际生活之间的差距。谢契依次修车接司机、从灰狗避难所接出运输员，再安排伤病住户与过冬粮食的运力。D-6 归队继续运输调度、供水修复和独立测量，不能直接转到敌对公社。

同行者实际走向接送点，走远会等伊万；没有到达不能当作已交接。带人返站以后，现场与人物日常保留结果。逃亡者重返矿区需私人接应、侦察和准备，公社文件没有通行效力；安娜同行另需确认带路人与退路，生还和悲剧保留各自后续。

完成阵营工作后取得星城技术联络线索。介绍信和家庭关系都不代替门禁：修复外线并独立核验、去污与武器登记后，才能进入有限工作区。父子相认、共同标定、追问通信记录分开进行，是否原谅父亲不锁死公共选择。

后半部核对不同地点的原始读数，组织预警与撤离。共享预警、中央调度、分散保全、留守观测各有三个现场阶段与不同后续。选方案不会立即结束；确认时单独保存“最终行动前”。终局后可以继续探索未完支线，也能读取这个独立档位尝试另一条方案。

新增七幅剧情插画、两首原创 MIDI 配乐及压缩录音。全屏过场逐段显示，明确说话者，读完才显示选择；段落进度随存档保留。已获项目方确认商用授权的电台歌曲继续保留。伊万已认可的四套图集未改动。

## 操作与保存

- WASD 移动，E 互动；多个相邻对象用滚轮选择。I 背包，J 手记，M 地图，Esc 暂停。
- 1 手动拔枪／收枪，鼠标瞄准，左键射击，R 换弹；Ctrl 轻步潜行。
- 空格补全当前文字，再按继续；图文选择需点击对应选项。
- 六个手动档位、三个自动档位及独立终局前档位；F5 保存选择，F9 读档选择。位置、物资、任务、人物移动、解锁和对话记录均保存。
- 固定分区界面，背包 8×6 实际占格，可拖放与旋转；商店分购买／出售，聚落柜子可寄存。
- 地表搜刮死亡丢失随身普通装备与物资，保护任务关键物品和聚落寄存物；剧情战斗可无损重试。返站缺装备时，寄存柜提供恢复外勤的借用套装。
- 画面设置提供分辨率、窗口模式、比例／填充与四档画质。更改后需在十五秒内确认，否则恢复。

## 工程与验证

源工程用 Godot 4.6.3 打开 `project.godot`。`bash tools/run.sh --test` 运行旧章节及完整流程检查。`tools/build_complete_campaign.py` 是后半部可编辑数据的生成源，生成 `data/complete_campaign.json`。修改文案时同时更新生成源。

当前检查包括状态与分支、实际寻路和同行、UI 尺寸、存档、任务目标、命中、资源与原生资源包启动。自动检查不能替代 Windows 真机长时间游玩、音乐实听与发行前人工验收；本库不把“流程可通关”称作已通过商业品质认证。

截图和版本资料放在独立资料分支。工程 `docs` 只保留当前素材示意和当前地图全景；旧版剧情动作因存档兼容仍可见于源码，正常新版流程使用新的限制与章节。
