## 本轮实装

- 修复先探索通信站时无法领取维修组件的任务依赖；目标随隔离、取件、供电和播放阶段更新。移除旧代码里覆盖新任务说明的重复逻辑。
- 真正隐藏占用房间的屋顶、雪层和顶梁。旧版屋顶被静态批处理复制，隐藏原节点仍会留下副本，本轮已排除这种情况。
- 进入城区开放室内时收近镜头、渐暗屋外；出门恢复。诊所、通信站与新增住宅使用同一机制。
- 工人街住宅增加四个分隔房间、厨房、床铺、书桌与两处容器；《厨房桌上的信》可收入手记阅读，刊物总数十九篇。
- 城区固定容器增至十四处，包、储物柜与木箱采用对应外形。支持容量安全的批量收取，剩余物品保留；搜空状态标在互动提示中。
- 手记各页与普通页面独立记住滚动位置；地图增加平面底图、缩放、拖动、目的地标记与设施悬停名称。
- 新碎石材质与坡面、住宅墙地面材质；清理若干进度不符的旁白、安娜提前知情选项及序章身份错误。

## 验证

[53 套测试的最终日志汇总](validation/results.json)。完整回归后修正了两项过时断言：刊物由十八篇增至十九篇，地图切换由按钮组改为下拉选择。新增体验测试及受影响的城市场景、刊物、身份与文本测试另行复跑；最新记录覆盖旧失败日志。

新增体验测试覆盖：电台优先与供电优先两种顺序、各阶段当前目标、家信只获取一次、新搜刮点可达、屋顶无残留副本、进出室内恢复、跨页面滚动位置、地图标记与不泄露未知遭遇、背包放不下时批量搜刮不丢物资。

软件渲染截图验证不代表硬件性能和听音验收，自动回归也不代表整部游戏已经达到发行品质。完整后半部、全地图美术、动作及叙事的实玩验收按制作稿继续推进。
