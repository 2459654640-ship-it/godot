## 实际完成的内容

公社第一次药品外勤重做为“寻找医护与药品—确认个人意愿与证词—落实通信—实际陪同撤回—安置后继续交谈”的流程。莉季娅沿场景通路行走，距离太远会等待，人物姓名和互动点跟随身体；正在移动时保存再读取，会继续当前路程。

| 阶段 | 实际玩法与变化 | 实景 |
|---|---|---|
| 临行 | 自愿接取，询问人员、回程与药品情况；领取武器并确认防护，南口有本班弹药与绷带 | [任务详情](screenshots/mission-journal.png) |
| 寻找 | 读南控制间线路图，经西侧廊道解决兽群，找到两只药箱与莉季娅；可读墙上的命令和等候处的交接纸 | [转移间](screenshots/medical-office.png) |
| 交谈 | 了解封锁经过，确认她愿意前往公社；选择署名核对或内部封存，保护家属信息 | [当面交谈](screenshots/witness-cinematic.png) |
| 通信 | 清理北口再使用信号箱，或隔离南控制间电源、找到匹配组件并修复备用有线机 | [备用机](screenshots/control-room.png) |
| 陪同 | 莉季娅实际走到南口，司机确认且人已到齐才可完成接送；可以先回聚落准备，进度保留 | [候车区](screenshots/waiting-bay.png) |
| 返回 | 独立的轨道车返程插画，与医务室安置场景分开；提前撤回使用另一段旁白 | [返程](screenshots/ride-cinematic.png) · [交接](screenshots/return-cinematic.png) |
| 后续 | 莉季娅与药箱在公社医务室出现，继续交谈可得可阅读的《这一班的交接》 | [医务室](screenshots/clinic-after-handover.png) · [后续对白](screenshots/lidiya-aftercare.png) |

备用有线机替代北口的第二场战斗，西侧首次遭遇仍需处理；本章没有新增“全程潜行免战”的通路。署名和封存影响证词的保存说明与交接回应，没有把这两种选择写成新的结局。

## 场景与声音

换乘站区分水磨石站台、湿区侧廊、铺砖转移间和下半部绿漆控制室。新增门框和两扇开着的门、桌灯、担架、线路设备、备件柜细节、接送物资和墙面交接记录；门口与通道保留可通行宽度。灯光集中在有人工作的位置，普通探索不再持续播放战斗配乐。

三张新插画用于转移间、轨道车返程和公社安置。新原创配乐《等到下一班》附压缩音频、MIDI 和来源说明，用于药品交接后的片段。当前使用程序合成钢琴与弦乐，没有重新录制演奏。伊万的四套已认可图集没有改动；莉季娅沿用现有医护图集和程序步态。

## 验证与仍需完成的工作

[55 套最终回归结果](validation/results.json)全部通过。新增样章 63 项检查包含实际世界实例、两种通信办法、真实人物走到南口、中途与抵达后的存读档、动态目标、药箱交付、返站人物、刊物奖励不重复、提前撤回和旧存档迁移。章节与叙事检查再次核对了新资源和分支。

截图来自实际 Godot Forward+ 软件 Vulkan 渲染，1440×900。自动测试中会关闭部分自动推进，并用测试脚本完成战斗及选择；它验证状态和通路，不能替代陌生玩家的完整盲玩。当前云环境使用虚拟音频后端，没有完成硬件听音或最终混音验收。

本轮补齐的是已有地下外勤章节。v31 制作书提出的“含东郊城市探索、约 45—60 分钟的完整质量样章”尚未全部完成，游玩时长也未做独立测量。城市与其它地图仍有美术和内容需要重制，后半部、星城内区与四类终局仍待实装；不能把本轮称为整部游戏达到商业发行标准。
