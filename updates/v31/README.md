## 灰狗命中修复

旧瞄准把光标投到统一低平面，而俯视镜头中的灰狗是竖立的人物图。鼠标放在上半身时，实际目标会落到其身后，射击方向的高度又被限制，出现看似瞄准却没有命中的情况。

现在按屏幕人物位置和实际身体高度计算瞄准，子弹仍进行真实碰撞检测，墙和掩体继续阻挡。保留灰狗 80 点生命及左轮每发 32 点伤害：无遮挡命中三发击倒。测试包含鼠标实际投影、头胸位置、连续开枪、实体掩体和最终击杀。

## 死亡后怎样再次出发

确认行动失败并回聚落后，显示[损失与下一步](screenshots/return-guide.png)。手记跟进真实的个人寄存柜，取回备用物资；缺少面具、滤毒罐或武器时，可在柜旁借用基础装备。装备齐全后，目标改为出站口，已有任务继续保留。

本轮没有改变已经确认的死亡规则：地表搜刮丢失普通随身物资与装备，保护任务物品、收藏和寄存物资；剧情战斗保留检查点重试。
