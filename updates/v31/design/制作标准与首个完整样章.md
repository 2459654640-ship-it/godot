# 制作标准与首个完整样章

2026-11-01。用户授权按正式游戏制作流程推进整体重制。v31 是其中界面和行动恢复流程的首轮实装，不代表整部游戏已完成、获奖或具备最终发行品质。

## 体验目标

苏式地下社会的日常、核冬天城市探索、与具体人物建立关系，是本作的主要体验。战斗、搜刮与阵营系统围绕这些体验安排。先完成一段能从头到尾独立游玩的高质量样章，再用相同标准扩展地图和章节。

样章选定公社第一次药品外勤，目标游玩时间约 45—60 分钟，需要实际试玩校准。地理框架沿用公社—地下联络口—东郊街区—任务设施—公社，避免再增加一张没有完成度的空地图。已有任务只是基础，需要在后续制作中重排现场事件与人物后果。

## 样章的完整经历

| 阶段 | 玩家经历 | 验收重点 |
|---|---|---|
| 认识 | 在聚落了解派工人与收药者，知道药送给谁、为什么需要伊万、什么地方仍不确定 | 首次自我介绍、人物知情范围、任务接取明确；没有一聊就接满多条支线 |
| 准备 | 查看目标，在柜中取放物资，购买或领取补给，确认防护与路线 | 所有常用操作在固定界面完成；物资不足有具体补救办法 |
| 出站 | 值守说明回程入口，过场建立地表空间与危险 | 画面、同行者和旁白与分支一致；地图显示已知道路与任务指向 |
| 探索 | 在街区辨路、搜刮，发现可阅读的住户故事；短路可探索，安全绕路也可行 | 可进入与封闭入口清楚；街角密度、建筑用途、材质、光照及碰撞逐段验收 |
| 冲突 | 一次有清楚预警和掩体的枪战或潜行，以及与药品去向有关的现场决定 | 人物动作、命中、受击、声音及敌人绕行可靠；选择通过实际行动落实 |
| 返回 | 沿来路撤回，交接药品并看到具体人物或生活变化 | 背包物品与交付一致；同行者、门禁、任务和返程图相符 |
| 后续 | 人物结束工作、照顾伤员或主动再找伊万 | 后果在场景里可见，下一阶段经生活间隔后开放 |

死亡是一条需要同样打磨的流程：确认行动损失，返回聚落，取回或借用装备，重新确认目标并出发。不能让玩家因丢掉装备而不知道如何继续。剧情战斗仍保留原来的检查点重试区分。

## 已落地的界面标准

- 导航、物品／目录、详情与操作分区固定；鼠标滚轮用于地图缩放，核心页面无需整页纵向浏览。
- 背包保留真实格子与摆放位置，分类用于高亮；关键文件与纪念物受保护。
- 商店先选物品，在固定详情区购买或出售；价格、库存、拥有数量及不能交易的原因可见。
- 任务的当前目标、地点、背景并列清楚；已完成任务显示结果，未接任务不会混入已接列表。
- 书刊正文与记录分页，完整内容保留；未知收藏保留剪影和轻度线索。
- 对话按段显示并逐段打字，话题独立分页，旧记录不挤占当前回应；翻话题页不重复执行剧情或发奖励。
- 寄存／搜刮采用两栏转移，存取支持单件和整组，容量不足不吞掉物资。
- 六个手动档位同时显示；设置和暂停使用相同的固定界面框架。

视觉使用深色面板、留白、明确的字体层级、克制的黄铜色与苏式档案编号。布局先保证真实信息与操作效率，继续通过不同分辨率与长文本实景检查打磨。当前没有把换皮视为整个美术重制已经完成。

## 场景与叙事的下一步制作标准

每个可游玩的街段先明确用途、道路连接、入口与探索收益，再安排破坏和生活痕迹。材质在玩家实际近景镜头下验收，不能只看全景。建筑内部要有合理设施、家具、照明与可达路径，场景用途不能仅靠房间名称说明。

每场戏写明人物目的、已知信息、参与原因、动作和结果；对白先表达清楚，再处理节奏与修辞。过场用在空间、关系或生活发生变化的位置。已批准的伊万图集保留，角色角度与比例按同一标准检查。

关卡、敌人和文案一起验收。准备、探索、冲突、安静片刻和返程需要有节奏变化，不能靠堆更多敌人或对话延长时间。让不了解任务的试玩者在没有开发者提示的情况下完成，记录其迷路、误解和失去兴趣的位置，再修改。

## 交付边界

v31 完成核心界面、灰狗瞄准修复和死亡返程引导；未重建整座城市、未增加本轮新怪物或角色、未实现星城内区和四类终局。后半部继续采用已经确认的“预警与撤离”方向，相关任务与人物方案见 v30。整体发售验收以完整流程实玩、全地图美术、声音、稳定性和发行构建为准。
