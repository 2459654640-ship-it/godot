## 如何体验新流程

正式小队路线在水厂取到滤芯后，归途支持中尉或劝双方和平归队，回作业层正式交接，再询问下一项工作。先回生活层与谢苗诺夫交谈，然后按手记目标去医务间和装备库。旧版在交接前丢失滤芯的归队存档会补回尚未签收的两箱；已经交接或随中尉运走的物资不会重复发放。

安娜寻亲线核实矿区身份、安排探视后，与哥哥会面即可进入床边过场；见面结束后再问医护是否需要帮助，可自愿接受夜班照护支线。旧探视存档可通过新对话补看会面，不强制重做已完成的任务。

[居民动作预览](animation) 仅展示实际接入的正背面绘制动作；侧面与斜方向不以未验收的生图替代原素材。
