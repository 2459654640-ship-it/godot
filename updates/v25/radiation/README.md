# 辐射分档更新

| 辐射值 | 实际效果 |
| --- | --- |
| 0–19 | 饱食至少 40，每活动 90 秒恢复 1 点生命 |
| 20–39 | 饱食至少 40，每活动 180 秒恢复 1 点生命 |
| 40–59 | 饱食至少 55，每活动 270 秒恢复 1 点生命 |
| 60–79 | 暂停自然恢复，伤药正常生效 |
| 80–100 | 暂停自然恢复，绷带与急救包恢复量为原来的 75% |

不会直接扣血、不降低移动速度或射击能力。降低数值后立即切换档位，没有永久惩罚。辐射来源区域上限从 60 调整到 100。

抗辐射药降低 20 点。D-6 医务间、矿区医护、公社负责人或安娜、谢契军需处可安排免费处置，每次降低 30 点，可以重复处理到零；普通医务伤口治疗保持原恢复量。免费处置不会复活已死亡人物或开放未抵达地图。

背包有状态说明入口、当前影响及伤药实际恢复量；HUD 显示状态，跨档有提醒。数值随原有存档保存，状态按数值计算。
