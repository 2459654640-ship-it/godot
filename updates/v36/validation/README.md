# v36 验证记录

本次用 Godot 4.6.3 运行工程回归，并用 Linux Vulkan 软件渲染器检查实景。独立游戏包已完成逐文件 SHA-256 校验和 Linux 原生启动。测试存档、立体场景和布局表都来自同一个 Godot 工程。

`urban_ecology_v36` 的 45 项专项检查覆盖地面网格与碰撞一致性、灰坑辐射和安全绕行、水厂从实际厂门进出、留置室双入口与切顶、名簿读取后保存、地下各新门的双向步行和新储料间的可达性。`campaign_contract` 的 525 项检查还覆盖现有设施的目标视线、位置、门洞与实际存读取。

部分长测试遇到并发运行时限后单独重跑。各项最终结果见 `results.json` 和同目录日志。Windows 真机兼容性、硬件帧率和真人长流程通关尚待验证。
