# 地铁1982 · v41 东郊冬季街景

东郊全图更新了漫射天光、斜向日光、屋顶薄雪和街面的冰水材质。旧电车站与工人街诊所采用有结构厚度的站车、围护与檐口。公社支线口通过门玻璃、搪瓷面板和灯具辨识。搜刮窗口可同时查阅容器、物品用途和入包后的位置。
