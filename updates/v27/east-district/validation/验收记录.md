# v27 验收记录

Godot 4.6.3 / Linux 云环境。50 组回归通过，合计 19254 项检查；末次补充验证了营地遮挡和混合遭遇的收尾。完整结果见 [results.json](results.json)。

- 既有九图流程、人物八方向、物品与商店、旧存档、对话、既有战斗与重试均保留测试。
- 新地表所有入口出生点通过实际角色体积重叠检查；锁门前后分别检查道路连通性，收音机桌面与操作面有通行空间。
- 实际验证室内外往返、供电动画、资源不可重复领取、配方消耗、阵营访问成本、旧通行标记无法解除通缉。
- 新营地测试守卫实际行走、视锥、掩体遮挡、轻步声音、渐进怀疑、无击杀取物、主动交火、脱离追击、人员伤势与巡逻读档、跨室内撤离后恢复、战前弹药重试，以及游荡兽群与营地混合后的正常结束。
- 四套伊万图集与 v26 对比一致，文件校验见 [ivan-preserved.json](ivan-preserved.json)。
- 实景使用 X11 / OpenGL compatibility / 软件渲染截图检查。未在用户的 RTX 4070 笔记本上做性能或硬件兼容测试。

首区美术与潜行仍可根据实际试玩继续细化；本报告不把完整后段剧情、星城内部、全部结局、新枪种或完整仓库系统列为已完成功能。
