## 本轮实际可玩

从公社或谢契的离站处可选择登上地表；正式归队者在 D-6 正门登记外勤。旧泵站任务先进入东郊工业片区，沿路找到独立泵站入口；从泵站撤回，回到同一个地表入口，再自行返回聚落。地图不是把三个聚落的本体放在相邻楼里：地表门口连接地下联络线，聚落仍是独立场景。

先辨认西南入口的旧导向图，取得街西维修间的匹配组件，到变配电所恢复电力。货场横穿门会沿围栏退开，指示灯与修配间通电；东侧检修库和北线入口可达。谢契一侧出发的玩家，可先从东侧应急柄打开横穿门，再去修复供电。开通道路不替代阵营担保，更不能直接进入星城内区。

铁路东侧的灰狗是人类土匪，有自己的住处、食物、物资和武器。可利用西侧围栏缺口、堆料与守卫朝向，按住 **Ctrl** 轻步潜入，或按 **1** 拔枪交战。守卫先起疑再报警，视线和枪击受真实掩体阻挡；失去目标后搜索最后线索，远离并藏好可以脱离追击。运输箱无需击杀守卫即可取得，核心奖励相同。人类守卫不随游荡怪物刷新复活。

首次秘密返矿需要先向公社联络员落实瓦西里的接应，再在档案处核对入口、班组和撤离方式。由地表水厂西侧检修巷进入煤运区，办完仍从内部接应原路退出。通缉没有撤销，作业层与生活层不因此开放。安娜后段专门救援关卡尚待按新身份规则接入。

废金属、铜线和修补布可收集、出售；通电的修配间提供两种基础制作。尚无背包容量、独立仓库或新枪种，不能把它们当作已完成的塔科夫物品系统。
