# 《地铁1982》剧情与玩法更新讨论稿

2026-10-23。以下区分本轮修复与待讨论方案；秘密返站、背包重构和新经济规则均尚未实装。

## 本轮实际修复

- **居民议事、谢契入伙轮值改为区域互动。**进入所在房间的参与区域即可按 E 打开活动；不再要求摸到讲台旁的单点。隔壁房间不能触发。附近 NPC、刊物等仍优先，滚轮可以切换。
- **地图指向更明确。**活动显示参与范围；其它正在跟进的目标在展开地图上显示位置。物件、设备和人物仍须靠近互动，不会隔墙交付或远程拾取。
- **D-6 身份检查统一。**对话、实际行动、过场及地图跳转使用同一判断。擅离、协助老兵离队或加入敌对阵营，都不能用公社材料取得公开返站资格。旧存档中的“已审核”“煤矿准入”也不能覆盖这些事实。
- **正常归队保留。**随队归还滤芯、未叛离或加入敌对阵营者，可以凭 D-6 本人的随队记录审核，交接后回生活层并继续既有外勤。
- **旧存档有退路。**已在作业层的受限身份可以退出；已在矿区的旧存档保留当前探索和物品，可以离矿返回公社。读到一半的旧返站过场不能继续把通缉者送进 D-6。
- **材料名称与用途修正。**原“公社探访函”改为“寻亲与班组抄页”，用于核实身份，不是通行证。百科不再暗示公社与中央有官方往来。

**当前限制：**按此次“先修漏洞，大剧情先给方案”的选择，秘密接应入口暂未开放。因此，逃亡者的安娜返站阶段、后续返站救援，以及公社的矿工征询阶段会保留任务并说明受阻原因，不判失败、不扣资源、不触发结局。现有阵营出站任务仍可继续。已有矿区存档可完成当前探访后离开，但不能借此获得下一次公开返站资格。这不是一份已完成秘密潜入章节的大版本。

## 建议的剧情更新：把返站做成章节

### 1. 先让身份真正影响路径

| 当前身份 | 可以做的事 | 必须付出的成本 |
| --- | --- | --- |
| 正常归队、交回滤芯 | 回家、接受 D-6 调派、经批准进入工作区域 | 内部观察与任务考核；不能自由代表公社活动 |
| 擅离或协助老兵离队 | 联系私人接应、从外围检修通路进矿区 | 获取信任、准备进退路线、避开检查；记录不会被一张纸洗掉 |
| 已加入公社 | 通过地下联络协助矿工、寻找安娜哥哥 | 保护接应人，不携带公开组织名单；暴露会影响后续联系 |
| 已加入谢契 | 经熟悉运输路线的人联系矿区 | 先取得对方愿意承担风险的理由；谢契身份不能替代 D-6 许可 |

正常归队继续的是中央路线，不等于自由往返敌对公社。应先安排有限权限和观察期，再让伊万逐步接触制度造成的实际后果。阵营转换需要剧情与代价，不能用一次普通对话完成。

### 2. 私人接应必须有来历

老兵认识一位矿区管理人员。若玩家已与老兵同行，由他直接牵线；若玩家独自逃离、尚未认识老兵，先经谢尔盖的运输关系找到联络线，不能凭空知道这个朋友。

接应人愿意帮助核实家属下落，但不会一上来就替公社组织政治活动。他也要保护矿工和家人。让玩家先了解他的顾虑，再决定哪些信息可以交给他，避免又变成“交一份文件就全信了”。

### 3. 进入、调查、撤离各有玩法

1. **准备：**与接应人确认会合办法，实地辨认入口，确认备用出口。准备来自行动与判断，不强制花钱购买主线唯一必需品。
2. **进入：**一张小型外围检修地图。先以视线、遮挡、巡逻和逐渐升高的怀疑构成基础潜行；观察后再移动。警戒和失败原因必须看得懂。
3. **矿区调查：**亲属身份、工伤记录、本人意愿分别核实。接应人只能提供自己知道的信息，医护决定照护安排，阿列克谢也应有自己的意见。
4. **撤离：**调查时发现原路线风险变化，玩家利用提前确认的出口离开；不依赖猜谜或未告知的隐藏道具。

被发现先给撤退或重试机会，不随机处决安娜。沿用已确认的“检查点重试不额外扣资源”。暴露对人际关系的长期影响，需要在具体分支定稿后另行确认。

### 4. 安娜线的情感落点

保留“给下层孩子教书”的生活目标。先通过一节课、一次陪同行程和她对哥哥的复杂感情建立人物，再进入救援。她不只等待玩家送消息，也会做安排、提出异议、承担选择。

生还路线要展现康复、照护与继续生活的难处；悲剧路线应完成她已开始的事，并留下人物和聚落的后续变化。避免用突然死亡制造震撼，或把她写成主角成长的工具。具体死亡条件、关键选择和最后一幕，仍需讨论后定稿。

## 背包、物品、商店：借鉴《逃离塔科夫》的建议

目标是让“出门前准备—探索搜刮—回来整理与交换”形成循环。保留本作重剧情、可读文案和箱庭探索的节奏。

### 第一阶段：背包有空间，装备有用途

- 背包采用真正的二维格子；小药品 1×1、罐头或工具 1×2、长枪占连续长格。尺寸按游戏内用途设计，避免所有物品都是同一个格子。
- 支持拖放、合法旋转、自动放入、整理、数量拆分与合并。位置冲突时显示放不下的原因；手柄或不习惯拖拽的玩家也能通过点击操作。
- 装备栏明确分开武器、防毒面具、滤毒罐、外套和背包。戴着的装备不重复占背包；换背包时原物品必须完整迁移，容量不足不能悄悄丢失。
- **主线纸条、钥匙、母亲照片放独立的证件/任务袋。**收藏刊物进入手记。两箱净水滤芯作为运输任务处理，不能缩成普通一格杂物。
- 第一版不加复杂负重惩罚，也不改现有死亡重试规则。先验证整理是否好用、探索收益是否清楚。

### 第二阶段：物品值得拿，也需要取舍

| 物品类别 | 游戏中的意义 |
| --- | --- |
| 食物、药品、滤毒罐 | 已有生存系统的准备与恢复；显示剩余份数或状态 |
| 弹药、武器零件 | 备战与少量明确的武器改善；暂不堆砌大量口径和配件 |
| 电池、铜线、轴承、工具 | 维修、制作、阵营委托与交易；同一物品可以有几个可信用途 |
| 怪物样本、骨片等 | 探索战斗的额外收益，交研究者或特定商人；不让每场战斗都只掉子弹 |
| 日用品、旧时代物件 | 少量有描述、有出处的世界细节；能卖、能送，部分可引出人物故事 |

首次拿到物品就看得懂用途。重要但暂时无用的物件可以先存仓库。任务需要的不可替代物品继续保护，不会因为误卖导致主线卡死。

### 第三阶段：商店从列表变成备战界面

- 保留购买/出售切换，左右同时看到商人库存与玩家物品；显示数量、单价、合计及购买后的资金。
- 不同商人的专长与收购偏好有区别。军需员、医护、机修工有各自的货物和需求，不让人人售卖同一套物资。
- 制式子弹仍是主要交易货币，土制弹仍用于主要战斗；暂不增加一堆新货币。少量物物交换可作为特殊交易。
- 库存、价格、个人仓库与交易记录进入存档。刷新库存不能靠反复打开界面，也不能存在买低卖高的无限套利。
- 阵营关系影响能接触的商人和特定货源，但主线最低补给仍可获得。支线与探索提供更充裕的准备和可选升级。

**建议的取舍：**借鉴背包空间、整理、物资用途和备战取舍；暂不引入死亡清空装备、离线饥饿、保险倒计时、复杂身体部位伤势。现有无损重试继续保留，除非之后明确讨论改变。

## 建议实施顺序

1. 先验收本轮互动与身份修复。
2. 确认返站章节的任务方式、人物动机和风险，再制作外围地图与关键过场。
3. 独立做背包与商店首版：规则格子、装备栏、仓库、明确买卖。用现有物品验证，不同时重写全部数值。
4. 再把搜刮、特殊收购与资源用途接进地表和阵营任务，按实际游玩结果调整收益。

## Meshy 角色制作

Blender 试作未达到要求，停止沿这条手工试作继续消耗时间。游戏继续使用已验收的 2D 伊万素材。

Meshy 值得单独验证：现有合格三视图 → 单个伊万模型 → 检查真实头身比例、侧背面和贴图 → 测试蒙皮与走路/持枪动作 → 固定相机渲染八方向动作。先验收一个角色，再决定是否扩展到 NPC。

当前未接通 Meshy 服务，也没有执行过 Meshy 生成。云端调用需要实际可用的服务账户或接口；不会要求在你的电脑部署模型。本轮不替换游戏人物、不继续修改已验收的 24 张基础动作。
