# v26 · 兽群与交火反馈

工程分支：[metro-v26-creature-combat](https://github.com/2459654640-ship-it/godot/tree/metro-v26-creature-combat)。

- 伏扑兽：0.9 秒伏低蓄势，地面标出锁定方向，随后向前扑击。可侧移或开枪打断，撞墙会停下，扑空后会恢复。
- 囊喉兽：保持距离，0.95 秒鼓起喉囊后喷吐。实体弹道不会追踪，能躲开，也会被掩体挡住。
- 两种怪物都有七种完整绘制姿态：站立、迈步 A、迈步 B、蓄势、攻击、受击、倒地。五个绘制角度加镜像覆盖八方向。整只身体统一缩放，没有剪切拼接腿部。
- 水厂三处、地表泵站两处及阵营线路兽群混合使用新旧种类。末段士兵配置保留。老兵自动协助机制保留。
- 实际命中与击杀有短促提示和音效；击中墙面不显示怪物命中。音效为原创合成，不加持续底噪。
- 战斗存档包含扑击方向、已命中状态、飞行弹道与剩余时间。暂停不推进，死亡仍能无损重试。旧存档已清理的遭遇不会重生。
