# v18 更新说明

## 伊万与居民

- 以 v3（057fff3）的伊万作为身份和美术参考，重新绘制八个独立方向，不再把斜后方走路帧折叠成镜像视图。
- 普通、戴面具每方向均有站立、左迈步、右迈步。持枪与换弹采用同一套腿部动作；头部固定，尺寸注册最多调整 3%，避免反复生成导致比例漂移。
- 播放顺序为迈步、站立、另一迈步、站立；低帧率时限制一次跨越的动画相位，保留落脚过程。
- 只有站姿的单人 NPC 使用轻量的二维腿部网格动作，保留原有贴图，效果较主要人物的完整绘制步态更简化。部分工作人物保持原地，其他居民只在自己的区域短距离活动；避让后自行走回。
- 群体 NPC 原地增加轻微呼吸、重心变化，每个人节奏略有不同；宽度仅缩减 3%。公社等候、阅读和议事人群重新安排位置。

## 音乐

- 伊万卧室旁的剧情收音机新增“打开音乐频道”，不触发星城信号任务。
- 普通 NPC 对话时继续播放音乐。图文过场、战斗和专属剧情音乐期间仍暂时停播。
- 卧室收音机按它自己的位置计算距离衰减，随身收音机保持随身播放。

## 查看资料

`screenshots` 为当前 Godot 实际渲染，GIF 可查看连续步态。游戏工程 docs 只保留当前人物参考和最新地图，不混入逐版本审阅截图。`art-source` 为本轮生成原图与 v3 参考，`packing-report.json` 记录打包参数；可用游戏工程的 `tools/pack_motion_v18.py --sources ... --report ...` 重现图集。

验证记录见 `validation.json`。旧测试中穿过新增收音机桌的路线已调整；检查后续剧情的测试会明确设置双方已相识，首次相识流程由独立测试覆盖。
