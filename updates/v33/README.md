## 剧情内容

三条阵营路线继续推进，加入阵营不结束游戏。公社：医护护送、运输员与私人书信、供暖与居民议事。谢契：修车接司机、潜入或交战救运输员、落实住户与粮食运力。D-6：伤员与燃料调度、实际供水、独立测量。长任务分阶段交接，同行者实际到达才计算返站；人物日常会改变。

逃亡者救安娜哥哥需要矿区内部接应、先前侦察与本班次准备，不能拿公社材料走 D-6 正门。安娜与医护从工友搬运支线进入，伊万单独走已侦察的检修路。生还／悲剧仍有各自后续，准备不足有明确暂缓选择。

星城新增有限工作区：介绍与家庭关系均不代替门禁，先修外线并独立核验。实际武器暂存／归还，家庭核对、初见、共同工作和通信责任分开谈；照片可展示并保留。临时技术交接不撤销逃亡身份。

后半部围绕有来源的风险测量、预警和撤离。四种方案都需要实际执行三个现场阶段，选择方向不直接结束；终局包含人物后续，仍可继续探索，确认前有独立存档。
