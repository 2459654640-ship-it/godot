# 验证范围

完整回归包含 58 套检查。首次回归有三项失败，分别是电台暂停声音退出后的 Ogg 播放对象残留、旧存档兼容迁移的断言预期、分段过场说话者的读取顺序。修复后按相关套件复验，最终结果全部通过，详见 final-results.json；保留首次回归记录以便追溯。

新增完整剧情状态检查 419 项，覆盖三条阵营线、独立核验、真实装备保管与四种执行后的终局。新地图实际寻路和六类护送检查 49 项通过；另有 2 项跨地图返站位置回归通过。最新过场／终局与网格面朝向检查 35 项通过。它们包含实际场景实例和物理行走，也包含显式模拟外部事实的状态测试，不能将后者当作真人完整通关。

十四张地图全景、主菜单、背包、任务、设置、六选项过场、父子对话与终局做了实际渲染核对。原生 Linux 导出模板在没有源码的包目录中启动，并通过鼠标点击进入新存档序章（native-title / native-prologue）；发布包使用同套资源和官方 Windows 模板。命令行 --script 不被 release 模板作为验证入口，未将该尝试算作运行验证。

环境使用软件 Vulkan；没有 Windows 真机性能数据，也没有音频设备实听验证。功能检查不等于美术、文学质量或商业发行认证。终局、存档及未完支线仍需要真人长时间游玩验收。
