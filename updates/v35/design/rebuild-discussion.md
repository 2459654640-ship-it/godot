# 场景、玩法与操作重制讨论稿

v35 用安娜的矿区转移验证一种章节结构。她与哥哥在床边谈妥走法，玩家带两人经过已认识的通路，看到提升机停摆，回到地图决定是否改走备用出口。场景、对话和任务状态来自同一件事，所以可以把它作为评估后续重制的样本。

| 范围 | 现在的问题 | 重制时用什么判断效果 |
| --- | --- | --- |
| 地表城区 | 从高处看是一张地图，从玩家身边看经常只有平面道路和封闭楼体。 | 先选一条完整街区，从下地铁、读路标、观察入口，到进楼、发现另一条退路。远处看得见方向，临街空间有落差、拐角和用途不同的入口。废楼可以从窗口、门和屋顶判断原用途。 |
| 地下箱庭 | 任务房常由走廊串联，换一张地图难以辨认自己到了什么地方。 | 先按设施用途布置煤运、供暖、居住和工作动线，再作玩家路线。关键房间具备独特的轮廓、声音或照明。箱庭的起点和返程会重复经过至少一个能看见变化的地点。 |
| 场景美术 | 材质已有不同版本，几何和尺度常不够可信，插画比实景复杂很多。 | 主建筑用米制模块和实测门窗，记忆点做专用模型，表面使用可复用材质。过场参照场景地标和比例。以正常游戏镜头检查轮廓、噪点、灯源、互动处的遮挡，再决定是否增加细节。 |
| 任务与剧情 | 任务有时通过交付和多次点击代替一场原本可以亲历的事件。 | 在玩家必须出手时交还控制，在表演、时间跨越和不可见场所用过场。一个动作可以同时改变通路、人物反应和记忆，而非拆成多个取件步骤。高潮的决定在玩家已有足够信息时出现。 |
| 操作 | 移动、交互、菜单与交火接缝上最容易出错。 | 用同一路线测试连续移动、开门、选中邻近人或物、切菜单、复位光标、读档与继续。危险能从声音和动作读懂，失败能知道原因，交火结束看得见下一步。也要测低画质和分辨率档位。 |
| 界面 | 固定分区解决了一些滚轮问题。关键提示仍有位置重复、重要度相近的情形。 | 操作手记看当前目标、位置与已知条件，地图负责行动方向，画面上只在需要时提示。用键鼠完整跑通背包、对话、地图与过场，避免一个按键跨两个语境触发。 |

主线用伊万亲身遇到的人和送不到的消息做联系。公社看到通知与供暖的差距，谢契看到运力和留守的代价，D-6 看到仓促批准与居民实际到站之间的矛盾。星城把各路证据变成同一个迫切问题，让等待的人知道该往哪里去。父亲和谢苗诺夫分别留在伊万的生活中，玩家能选择怎样继续相处。

建议后续先以同一套验收方式打磨从 D-6 觉醒到水厂返程这一段，再把地表第一条可探索街区与往返手续接起来。这两段能直接检验开场节奏、操作、战斗和画面。按镜头与实际路线验收后再向全图推广，能尽早看见设计是否在游玩中成立。
