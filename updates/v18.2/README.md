# v18.2 伊万重复迈腿修正

四个斜方向与向右行走的两个迈步帧，先前虽然文件不同，但落脚与抬脚的关系近似相同，导致视觉上只迈同一侧腿。本轮为这五个方向独立补绘另一个迈步姿态的腿部，保留两腿并拢的过渡帧。

普通、面具、持枪、移动换弹同步替换，累计仅修改 30 个迈步帧的腿部。160 个生产帧逐像素核对：头部、躯干、手部及装备保持不变，未涉及的帧完全一致。没有更改播放速度、其它方向和 NPC。

新增的 30 项落脚检查核对两个迈步帧的下方落脚靴是否换边，旧素材全部无法通过，新素材全部通过；这项检查结合人工并排观察，避免只凭帧编号或文件不同就认定已经换腿。完整动作检查 1024 项、八方向检查 7254 项通过，见 validation.json。逐帧保留情况与落脚数据见 preserved-frames.json、foot-contact-audit.json。

这里的 PNG/GIF 为 Godot 实际渲染。GIF 顺序为迈步、并拢、另一迈步、并拢。生成素材仅取腿部，头身仍使用原有生产帧。若重打包，请将此处 art-source 文件覆盖到 updates/v18/art-source 的原图目录，再运行游戏工程 tools/pack_motion_v18.py；其中 opposite-strides.json 指定五个独立修正源。
