# v22 剧情条件与验证（含剧透）

## 开始与阵营

首次进入 D-6 作业层呈现病房广播，也可在医务间再次调查未读内容。加入公社或谢契后，找各自守备／军需轮值员明确接取出站任务，随后在出发登记处启程。前一轮交回记录后才开放下一轮。

公社三轮：药箱经过的地方 → 被截住的回信 → 最后一班撤离车。
谢契三轮：空车也要回家 → 没有旗子的车队 → 报复到哪里为止。

每轮在旧联络线查南控制间线路图、处理西侧威胁、调查转移点并作出选择、处理北口威胁、接通信号，最后返回派工者汇报。前两轮面对变异兽，第三轮面对持枪封锁队。途中决定会改变返程的相应段落。复用同一地理区域，各轮进度、战斗和报酬独立。可先撤回再继续，补给和报酬不会重复领取；主线路径在战斗前补足最低弹药。

正式双阵营入伙互斥。完成实际出站工作后，可以申请具名担保，承担一班联络交接后访问另一处聚落；一次通行安排在出发时消耗，下次访问重新申请。没有实现随意换阵营或正式叛离剧情。

## 安娜：认识、准备、结果

安娜在公社医务室教孩子，哥哥阿列克谢在 D-6。先完成自我介绍，再问课堂；课堂过场不会自动接任务，回到对话后才可明确答应寻亲。查交换记录，经过 D-6 返站审核，从下层检票口入煤运区，逐步核实身份、照护和本人意愿。带回首封探视结果后，仍只是故事前段。

完成一轮阵营出站任务，或完成旧泵站污染调查并交付后，她的新来信才开放。玩家可以一直不接，不会自动死亡。准备医护、接送、休养铺位，与她出发后查矿区原始回风图、打开最西侧旧支巷的备用出口。三项关键条件为医护、矿口接送、备用出口；医护与接送即使出发前没办，也可在矿区补办，不花强制子弹，不要求维生素 D。休养铺位是生活准备，维生素按医护计划用于后续照护，二者不暗中判定死亡。

撤离前在值班医护或安娜处核对。条件齐全才显示安全方案；不足时显示暂缓与明确的风险方案，后者还需第二次确认。阅读、交谈和暂时离开不触发事故。安全方案生还，回公社后还有休养、教课的后续；完成后期北线主线以后可以约她看地表。风险方案触发事故，之后继续搜索、交代、整理课本，再选择家属如何处理事故记录。死亡后她的 NPC 不会继续留在场景里接任务，哥哥会在公社接受照护。安娜死亡不会结束或阻塞阵营主线。

## 星城

完成本阵营三轮出站主线，并看完返程广播，再向轮值员核对东方-7、领取询问信。谢契还需原有电台和列车检修条件。到达后只能在外围询问、留信、返回，内区与父亲重逢不在本次开放范围。既有内区素材和历史记录不删除。

## 音乐与附件

四首原创 MIDI 与相同音符事件渲染的 WAV 已接入：来信以后、还可以安排明天、留给下一班的课、南口识别灯。只在指定节点或战斗播放，通过 Music 音量控制；普通 NPC 对话仍不会暂停公共收音机。

《我要你（俄语版）》由用户 MP3 转为与现有曲库一致的 Ogg，约 179.5 秒，原位置不变。另两首 WAV 因单文件大于 32 MiB，工具返回读取上限，未取得音频、未转 MP3。远洋频道配置在 `data/radio.json` 的 optional_stations / optional_tracks；实际的 `assets/audio/radio/moon_heart.mp3` 与 `only_care_about_you.mp3` 两个文件均存在并导入后才注册，避免出现不能播放的曲目。需要用户提供每份不超过 32 MiB 的 MP3 或较小音源。

## 测试和限制

运行断言见 validation.json 与 logs。覆盖旧玩法、九图加载与存档、交互可达性和视线、控制间门口双向通行、矿区闸门动画、真实武装伤害、检查点资源恢复、八种准备组合、两种结局、旧存档迁移与一次性资源。截图由虚拟显示器中的 Godot OpenGL / Mesa 实际渲染。音频文件已检查可解码、长度和峰值；本环境没有人工听音验收。

伊万专用手部换弹绘制仍未定稿，当前以完整持枪图保持三姿态移动、配合装填计时和声音，不使用旧的拼接上身。星城内区、正式叛离流程和阵营大战的更长期后续不在本次开放范围。
