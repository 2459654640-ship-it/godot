# 伊万 · 多视图 AI 建模试作要求

目标是生成可绑定、可动画的人物模型，随后在独立场景中检查。当前阶段只制作参考图，不修改游戏本体。

## 参考依据

直接依据最初认可的八方向站姿中的正面、侧面和背面。原图来源与 SHA-256 见 reference-provenance.json。三视图是新生成的建模候选稿，尚未经过用户验收，不作为已认可的新外观。

## 第一轮范围

仅普通伊万：保留原外观、衣服、围巾和小背包。不带枪、不戴面具。成年男性，约 1.75 米，正常头身比例，瘦而不单薄。平视正交三视图，统一轻度 A 字站姿、相同尺度和中性光照。测试中背包可以先随胸腔刚性运动；正式版本再考虑拆成独立挂接部件。

## 上传方式

支持多视图输入时，分别上传 front.png、side.png、back.png，使用平台对应的方向标注。不要把三个角色并排的总图当作单张角色照片上传：平台可能把它识别成三个角色。每张单图只包含一个全身人物，保留完整头发、手指与鞋底。transparent 目录为透明版，neutral 目录为中性底版；选择其中一套，不要重复上传同一视角。

当前没有验证任何指定平台的实时接口或价格，因此本包不附猜测的 API 请求、未经验证的参数或自动扣费脚本。

## 生成时优先考虑

- 成熟的写实比例、完整手指、两条分开的裤腿和自然鞋型。
- 清楚的夹克轮廓、缝线、围巾、皮带和背包结构。保持原图的灰绿、棕和炭灰色系。
- 输出可用的网格和贴图，优先 GLB；若绑定服务需要，另留 FBX。纹理可先用 2K。模型分辨率先保留生成原稿，再在验收后减面，避免为追求小体积先破坏手部和衣服轮廓。
- AI 网格未经检查之前，不将其称为可动画或游戏可用模型。关节处拓扑、背包穿插和骨骼权重需要另验。

## 模型外形验收（先于动画）

在相同正交镜头中对照认可参考：头颅、头身比例、肩宽、腰围、手掌和鞋子不能变大；正侧背面衣服结构一致。检查腋下、裆部、指间是否粘连，以及透明片、破面、明显缺失和背包融合。输出转台和实际游戏俯视角静态预览后，再决定是否进入绑定。

## 下一阶段

采用统一人形骨架；先验证行走、转向、持枪移动和边走边换弹，检查足部接地、滑步、关节变形和脚掌外撇。动作与外形均通过之后，才考虑游戏接入与其它角色。

## 尚需条件

实际生成 3D 网格需要可用的 Meshy、Tripo、Rodin 等建模服务，或安装完毕并验证过的本地图片转模型流程。目前此环境未配置这些服务的 API 凭据，也没有安装本地 AI 建模模型。
